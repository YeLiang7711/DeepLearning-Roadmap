# 文字规则详解与范例

## 叙事弧：从例子到抽象

用户多次反馈"看不懂"都源于同一个模式：从定义出发。标准范例是 1.3.2（贝叶斯）和 1.3.4（MLE/MAP）。

### 范例对照：旧写法 vs 新写法

**旧（被否定）**：
```
贝叶斯公式：P(B|A) = P(A|B)P(B)/P(A)
其中 P(B) 是先验，P(A|B) 是似然，P(B|A) 是后验……
```

**新（被认可）**：
```
某种罕见病发病率 1%，检测准确率 99%。
你检测阳性，真正患病的概率是多少？直觉说 99%，错了。
10000 人算账：99 真阳性 + 99 假阳性 → 99/198 ≈ 50%
从算账过程提炼公式 → 术语（先验/似然/后验）对照回例子
```

### 每节的固定结构

```
## 从一个问题开始（带数字的具体例子）
→ 一步步算/走完例子
→ "回头看就清楚了" 引出公式
→ 术语表（每个术语对照回例子）
→ 在 DL 中（具体落点：VAE 编码器 = 后验近似等）
→ ## 总结（表格 + 加粗一句话）
```

| 路线图要求的程度 | 写法 |

## 终端兼容细则

Obsidian 渲染 LaTeX，但用户在 Claude Code 终端里读对话。终端会吞掉 `$...$` 行内公式。

**规则**：解释性句子中的变量一律纯文本，公式只在独立公式块 `$$...$$` 或不需要在终端读的场景使用。

```
✅ 错误：我想知道 $B$ 是否成立，从 $A$ 反推 $B$
❌ 正确：我想知道 B 是否成立，从 A 反推 B
✅ 公式块：$$P(B|A) = \frac{P(A|B)P(B)}{P(A)}$$（Obsidian 渲染）
```

## 表格内 LaTeX 竖线

markdown 表格单元格内的裸 `|` 会被解析器当作分隔符吞掉（用户实际遇到过的 bug）。

| 用途 | 正确写法 | 错误写法 |
|---|---|---|
| 绝对值 | `$\lvert \hat{y} - y \rvert$` | `$|\hat{y} - y|$` |
| 范数 | `$\|\mathbf{x}\|_2$` | 同上（`\|` 是转义符，安全） |
| 条件概率 | `$P(A \mid B)$` | `$P(A | B)$` |
| 行列式 | `$\det(\mathbf{\Sigma})$` | `$|\mathbf{\Sigma}|$` |

## 专业术语首现给中文全称

用户问过："高斯分布就是正态分布吗？""Mahalanobis 距离就是马氏距离吗？"——这些问题说明首现术语必须给全称对照。

| 术语 | 补充 |
|---|---|
| 高斯分布 | = 正态分布，$\mathcal{N}$ 是 Normal 的缩写 |
| Mahalanobis 距离 | = 马氏距离，印度统计学家命名 |
| PCA | 主成分分析（Principal Component Analysis） |
| SVD | 奇异值分解（Singular Value Decomposition） |
| PLSR | 偏最小二乘回归，**不是深度学习** |

## 符号说明

第一次出现的非常规符号必须说明。用户问过"概率计算中的 · 是什么意思"。

```
$P(A) \cdot P(B)$ 中的 · 就是普通乘法，和 × 没有区别
$P(A \mid B)$ 中的竖线读作"给定"或"在…条件下"
```

## 一句话总结范例

> 内积 = 对应相乘再求和 = 一个衡量"两个东西有多配"的数字。在 DL 里，全连接层用它做线性变换，Attention 用它判断词与词之间的关联。

> 贝叶斯公式 = 逆推。你知道"因→果"的概率，观测到了果，反推因的概率。先验是反推的起点，似然是数据的修正力，后验是综合判断。

> 多元高斯 = 在一元高斯的指数里，把"除以方差"替换成"乘以协方差的逆"，把一维距离换成多维 Mahalanobis 距离。
