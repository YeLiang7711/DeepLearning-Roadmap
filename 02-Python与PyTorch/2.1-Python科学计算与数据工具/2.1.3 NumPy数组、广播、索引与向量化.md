## 为什么 NumPy 是深度学习的地基

你的温度矩阵（100×100 个测温度）如果用 Python 列表存，加减乘除要写 for 循环，慢 100 倍。

NumPy 的 **ndarray（N 维数组）** 解决两件事：

1. **速度**：底层是 C 语言，向量化运算比 Python 循环快 10~100 倍
2. **语义**：shape 描述数据的结构——(100, 100) 就是一张温度图，(32, 1, 64, 64) 就是一批图像

> PyTorch 的 Tensor 就是"带自动微分的 NumPy 数组"——2.2.1 会看到它们几乎一一对应。

## 创建数组

```python
import numpy as np

# 从列表创建
temps = np.array([[25.1, 25.2, 25.0],
                  [25.3, 25.4, 25.2]])      # shape (2, 3)

# 全零 / 全一 / 均匀 / 随机
np.zeros((2, 3))                  # 全 0
np.ones((1, 64, 64))              # 全 1（模拟空白图像）
np.arange(10)                     # [0,1,2,...,9]
np.linspace(0, 1, 5)              # [0, 0.25, 0.5, 0.75, 1]
np.random.randn(100, 100)         # 标准正态随机（温度噪声模拟）

# 单位矩阵
np.eye(3)
```

### 三个必懂的属性

```python
a = np.zeros((2, 3))
a.shape        # (2, 3) —— 每个维度的长度
a.dtype        # float64 —— 元素类型（决定内存和精度）
a.ndim         # 2 —— 维度数
```

> **shape 是调试的第一检查项**。训练报错 90% 是"shape 对不上"——先打印 `.shape` 看谁和谁不匹配。

## reshape：不改数据改形状

```python
img = np.arange(12)               # 一维：12 个元素
img.reshape(3, 4)                 # 3×4 矩阵（元素顺序不变）
img.reshape(1, 3, 4)              # 加通道维度（单通道图像）
img.reshape(-1, 4)                # -1 = 自动推断 → (3, 4)
img.flatten()                     # 拉平成 1D（模型输入用）
```

**DL 场景**：图像 (C,H,W) ↔ 展平向量（全连接层输入）↔ 加 batch 维度，全靠 reshape。

## 索引与切片：取数据的任意部分

```python
a = np.arange(25).reshape(5, 5)   # 5×5 矩阵

a[0]              # 第 0 行
a[2, 3]           # 第 2 行第 3 列 = 13
a[:, 1]           # 所有行的第 1 列（列向量）
a[1:4, 1:4]       # 子矩阵（行 1~3，列 1~3）—— ROI 裁剪！

# 布尔索引 —— 条件筛选
a[a > 15]         # 所有大于 15 的元素（一维结果）
a[(a > 5) & (a < 10)]   # 区间筛选

# 掩膜操作（温度数据的坏点处理）
mask = (a == 0)
a[mask] = np.nan   # 把 0 值标为缺失
```

> **ROI 裁剪 = 切片**：`roi = temps[y0:y1, x0:x1]`。温度图的对齐、裁剪、取区域全靠切片。

## 广播（broadcasting）：形状不同也能算

### 规则：从后往前对齐，维度要么相等、要么是 1、要么缺失

```python
# 标量 + 数组：每个元素都加
temps + 2.0              # (100,100) + 标量 → 每个点 +2（温漂校正！）

# 行向量 + 矩阵：行向量自动扩展到每一行
centered = temps - temps.mean(axis=0)   # (100,100) - (100,) → 每列减均值

# 列向量 + 矩阵
scale = np.ones((100, 1)) * 2
temps * scale            # (100,100) * (100,1) → 每行乘 2
```

### 为什么能这样算

```
数组 A: (100, 100)
数组 B: (100,)        ← 维度缺失，自动补成 (1, 100)
对齐后: (100, 100)     ← 维度 1 扩展成 100
结果:   (100, 100)
```

**规则一句话**：从最后一个维度往前对齐，每个位置上两数组的维度必须**相等或有一个是 1**，1 会被自动扩展。

### 常见的广播错误

```python
a = np.zeros((100, 100))
b = np.zeros((100,))
a + b          # ✅ (100,100) + (100,) → OK，b 补成 (1,100)

c = np.zeros((100, 1))
a + c          # ✅ (100,100) + (100,1) → OK，c 扩展成 (100,100)

d = np.zeros((100,))
a + d.T        # ❌ d.T 还是 (100,)，不报错但语义可能不是你要的
e = np.zeros((1, 100))
a + e          # ❌ (100,100) vs (1,100)：从后往前 100=100 对齐，
               #    但第 0 维 100 vs 1 → 1 扩展成 100 → 实际 OK！
```

> **广播是最容易踩坑的地方**：shape 不匹配不一定会报错（可能悄悄算错）。验证方法：算之前打印两个数组的 `.shape`。

## 向量化：用数组运算代替 for 循环

### 为什么必须向量化

```python
# ❌ 慢（Python 循环，10000 个元素要循环 10000 次）
for i in range(10000):
    y[i] = x[i] * 2 + 1

# ✅ 快（C 语言一次算完）
y = x * 2 + 1
```

### 温度数据预处理的典型向量化

```python
temps = np.random.randn(100, 100) * 3 + 25    # 模拟温度图

# 1. Z-score 标准化（每张图减均值除标准差）
norm = (temps - temps.mean()) / temps.std()

# 2. 坏点掩膜：|z| > 5 的视为坏点
bad = np.abs(norm) > 5
temps[bad] = np.nan

# 3. 统计
temps.mean()          # 全图均值
temps.std(axis=0)     # 每列标准差（axis=0 = 沿行方向压缩）
temps.max(axis=1)     # 每行最大值
```

### axis 的理解

```
axis=0 → 沿"行"方向压缩 → 得到每列的结果
axis=1 → 沿"列"方向压缩 → 得到每行的结果
axis=None（默认）→ 全部元素压缩成标量
```

## 矩阵乘法与常用运算

```python
A = np.random.randn(10, 20)
B = np.random.randn(20, 5)

# 矩阵乘法（形状: (10,20) @ (20,5) → (10,5)）
C = A @ B

# 逐元素乘法（Hadamard 积，1.1.1 讲过）
D = A * A

# 线性层前向 = 矩阵乘法 + 偏置（1.1.1 的全连接层！）
output = A @ B + 0.1

# 统计与线性代数
np.linalg.svd(A)          # 奇异值分解（1.1.4）
np.linalg.inv(A @ A.T)    # 矩阵求逆
np.cov(temps)             # 协方差矩阵（1.1.5 / PaDiM 用）
```

## 和 PyTorch 的对应

| NumPy | PyTorch Tensor |
|---|---|
| `np.array([1,2,3])` | `torch.tensor([1,2,3])` |
| `a.shape` | `a.shape` |
| `a.reshape(-1)` | `a.view(-1)` |
| `a @ b` | `a @ b` |
| `a.mean()` | `a.mean()` |
| `np.random.randn(3)` | `torch.randn(3)` |
| 转换 | `torch.from_numpy(a)` / `a.numpy()` |

**几乎一一对应**——学会 NumPy = 学会 PyTorch 张量操作（2.2.1 展开）。

## 总结

| 概念 | 一句话 |
|---|---|
| ndarray | N 维数组：shape 描述结构、dtype 决定精度 |
| reshape | 改形状不改数据（-1 自动推断） |
| 切片 | ROI 裁剪、掩膜处理就是索引 |
| 广播 | 从后往前对齐，维度相等或为 1；1 自动扩展 |
| 向量化 | 用数组运算代替 for 循环（快 10~100 倍） |
| axis | 沿哪个方向压缩（0=行方向，1=列方向） |
| PyTorch 对应 | Tensor = 带自动微分的 NumPy |

> NumPy 的核心能力一句话：**用 shape 描述数据、用向量化运算处理数据、用广播避免写循环**。它是所有数据预处理的地基——温度图的标准化、坏点处理、ROI 裁剪都是 NumPy 几行代码的事。
