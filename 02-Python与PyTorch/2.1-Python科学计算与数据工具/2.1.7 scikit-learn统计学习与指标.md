## scikit-learn 是什么

传统机器学习的"标准工具箱"——**不需要深度学习的任务**（或作为深度学习基线的任务）都用它。

| 类别 | 工具 | DL 中的用途 |
|---|---|---|
| 降维 | PCA、KernelPCA | 1.1.6 的 PCA 实战、可视化 |
| 协方差 | LedoitWolf、ShrunkCovariance | 1.3.7 的协方差收缩（PaDiM） |
| 聚类 | KMeans、DBSCAN | 数据探索、伪标签 |
| 分类 | SVM、逻辑回归、RandomForest | 传统基线、特征评估 |
| 异常检测 | IsolationForest、OneClassSVM | 11-异常检测基础的统计基线 |
| 指标 | accuracy、AUROC、F1、confusion_matrix | 模型评估（1.3.5） |
| 预处理 | StandardScaler、MinMaxScaler | 特征标准化（1.1.6 实践要点） |

## 统一的 API：fit / transform / predict

scikit-learn 所有模型共用一套接口，学会一个就会全部：

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score, roc_auc_score

# 1. 预处理：标准化（fit 训练集，transform 测试集 —— 1.1.6 的数据泄漏要点）
scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)   # fit + transform 一步
X_test_s = scaler.transform(X_test)         # 只 transform！绝不再 fit

# 2. 降维
pca = PCA(n_components=50)
X_train_pca = pca.fit_transform(X_train_s)

# 3. 分类
clf = SVC(probability=True)
clf.fit(X_train_pca, y_train)

# 4. 评估
pred = clf.predict(X_test_pca)
prob = clf.predict_proba(X_test_pca)[:, 1]
accuracy_score(y_test, pred)          # 准确率
roc_auc_score(y_test, prob)           # AUROC（1.3.5）
```

> **数据泄漏红线（1.1.6 强调过）**：scaler/PCA 只能 `fit` 在训练集上，测试集只 `transform`。在测试集上重新 fit = 数据泄漏 = 指标虚高。

## 三大常用工具

### 1. PCA（1.1.6 的实战落地）

```python
pca = PCA(n_components=0.95)      # 保留 95% 方差，自动选 k
X_pca = pca.fit_transform(X)

pca.explained_variance_ratio_     # 每个主成分解释的方差比例
pca.explained_variance_ratio_.sum()   # 累积（≥0.95）
```

### 2. 协方差收缩（1.3.7 的 PaDiM 工具）

```python
from sklearn.covariance import LedoitWolf

lw = LedoitWolf().fit(features)     # 自动选择收缩强度
prec = lw.precision_                # 收缩后的 Σ⁻¹（Mahalanobis 距离用）
```

### 3. 聚类

```python
from sklearn.cluster import KMeans, DBSCAN

kmeans = KMeans(n_clusters=3).fit(X)
kmeans.labels_                      # 每个样本的簇标签

dbscan = DBSCAN(eps=0.5).fit(X)     # 不需要指定簇数，自动发现
```

## 异常检测的传统基线（11 章的前奏）

```python
from sklearn.ensemble import IsolationForest
from sklearn.svm import OneClassSVM

# 只喂正常数据训练
iso = IsolationForest(contamination=0.05)
iso.fit(X_normal)
scores = iso.score_samples(X_test)      # 分数越低越异常

ocsvm = OneClassSVM(nu=0.05)
ocsvm.fit(X_normal)
pred = ocsvm.predict(X_test)            # 1=正常, -1=异常
```

> **路线图的用法**：任何新方法（AE、PatchCore...）都要先和这些统计基线对比——"新模型是否在同一误报约束下真正提高了召回"（路线图结语）。这些基线就是 B0/B1（Median/MAD、PCA）的 sklearn 实现。

## 指标：评估的公共语言

```python
from sklearn.metrics import (accuracy_score, precision_score, recall_score,
                             f1_score, roc_auc_score, confusion_matrix,
                             classification_report)

# 分类全套
print(classification_report(y_test, pred))   # 每类的 P/R/F1
confusion_matrix(y_test, pred)               # 混淆矩阵（1.3.5 的两类错误）

# 异常检测关键指标
roc_auc_score(y_test, scores)                # AUROC（1.3.5）
# 固定误报率下的召回 —— 工业场景核心（路线图 16 章）
```

## 与深度学习的配合

```
传统方法（sklearn）                    深度方法（PyTorch）
───────────────                      ──────────────
数据标准化、PCA 降维       →         输入预处理
SVM/森林/聚类 基线         →         深度学习模型
指标（AUROC/F1/混淆矩阵）   →         评估（两者共用）
IsolationForest/OCSVM     →         深度异常检测（11 章）
```

**路线图定位**：scikit-learn 是"先建立简单可靠的基线，再增加复杂度"（学习原则）的落地工具——深度模型之前，先跑一遍传统基线。

## 总结

| 概念 | 一句话 |
|---|---|
| 统一 API | fit（训练）/transform（转换）/predict（预测） |
| 数据泄漏 | 预处理只在训练集 fit，测试集只 transform |
| PCA/协方差 | 1.1.6/1.3.7 的实战工具 |
| 异常检测基线 | IsolationForest/OCSVM = 深度方法的对照 |
| 指标 | AUROC/F1/混淆矩阵 = 评估的公共语言 |

> scikit-learn 一句话：**传统机器学习的标准工具箱**。在"先基线后深度"的原则下，它的 PCA、统计基线、指标是每个深度学习项目的第一站和对照系。
