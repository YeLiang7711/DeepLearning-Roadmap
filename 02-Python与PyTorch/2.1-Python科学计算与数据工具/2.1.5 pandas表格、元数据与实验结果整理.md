## pandas 是什么

NumPy 管**数值数组**，pandas 管**带标签的表格**——像 Excel 的 Python 版本。

| | NumPy 数组 | pandas DataFrame |
|---|---|---|
| 维度 | N 维 | 二维表格 |
| 每列有名字？ | ❌ | ✅（列名） |
| 每行有索引？ | ❌ | ✅（行索引） |
| 混合类型？ | ❌（必须同类型） | ✅（每列可不同类型） |
| 场景 | 数值运算 | 数据组织、元数据、结果汇总 |

**DL 中的定位**：温度矩阵是 NumPy 的活；但"哪个批次、什么环境温度、什么设备状态"这些**元数据**是 pandas 的活。

---

## 两个核心结构

### Series：带标签的一维数组（= 一列）

```python
import pandas as pd

batch_temps = pd.Series([25.1, 25.3, 24.9], index=["A", "B", "C"])
batch_temps["A"]        # 25.1（按标签取）
batch_temps.mean()      # 25.1
```

### DataFrame：带标签的表格（= 多列 Series）

```python
df = pd.DataFrame({
    "批次":   ["A", "B", "C", "D"],
    "环境温度": [22.0, 23.5, 21.0, 24.0],
    "设备状态": ["正常", "正常", "维护后", "正常"],
    "平均温度": [25.1, 25.3, 24.9, 25.0],
})
```

| | 批次 | 环境温度 | 设备状态 | 平均温度 |
|---|---|---|---|---|
| 0 | A | 22.0 | 正常 | 25.1 |
| 1 | B | 23.5 | 正常 | 25.3 |
| 2 | C | 21.0 | 维护后 | 24.9 |
| 3 | D | 24.0 | 正常 | 25.0 |

## 选择数据：列、行、条件

```python
df["平均温度"]              # 选一列（Series）
df[["批次", "平均温度"]]    # 选多列（DataFrame）
df.iloc[2]                 # 第 2 行（位置索引）
df.loc[df["批次"] == "C"]  # 按条件选行

# 条件筛选 —— 最常用
maintenance = df[df["设备状态"] == "维护后"]
high_temp = df[df["平均温度"] > 25.0]

# 组合条件
sel = df[(df["平均温度"] > 25.0) & (df["环境温度"] < 23.0)]
```

> **与 NumPy 布尔索引同款**：`df[条件]` 就是 2.1.3 讲的布尔掩膜，只是加上了列名。

## 分组与汇总：实验结果整理的核心

```python
# groupby：按列分组，再聚合
df.groupby("设备状态")["平均温度"].mean()
# 设备状态
# 正常     25.13
# 维护后   24.90

# 多列聚合
df.groupby("设备状态").agg({
    "平均温度": ["mean", "std"],
    "环境温度": "mean",
})

# 常用聚合：mean / std / min / max / count / median
df["平均温度"].describe()
# count 4, mean 25.075, std 0.170, min 24.9, max 25.3
```

> **路线图 2.1.9 的数据组织**：每个模型跑 N 个种子，结果存成一个表（模型/种子/准确率/训练时间），`groupby("模型").agg(...)` 一行出汇总对比表。

## 缺失值处理

```python
df.isna().sum()            # 每列缺多少
df.dropna()                # 删除有缺失的行
df.fillna(25.0)            # 用固定值填充
df["平均温度"].fillna(df["平均温度"].median())   # 用中位数填充
```

> 实验记录常有缺失（某次运行中断、某个传感器没记录）——**记录缺失比假装没有更专业**：`isna()` 统计缺失，决定是删还是填。

## 与深度学习的完整配合

```
温度矩阵（NumPy 的活）         元数据（pandas 的活）
─────────────────────        ─────────────────────
100×100 温度图 → 模型输入      批次/环境/设备状态 → 实验管理
损失曲线 → 训练监控            模型×种子×指标 → 结果对比表
```

**典型流程**：

```python
# 1. 读实验记录
meta = pd.read_csv("experiments.csv")

# 2. 按环境温度分组看正常分数分布（发现"捷径"！）
meta.groupby("环境温度区间")["正常分数"].mean()

# 3. 不同模型的结果对比
results = pd.DataFrame(all_results)
results.groupby("model")["auroc"].agg(["mean", "std"])
```

> **异常检测的关键用法**：按环境/批次/设备分组看分数——如果"正常分数"随环境温度明显变化，说明模型把环境当成了特征（1.3.8 的捷径、34. 因果泛化的问题）。

## 总结

| 概念 | 一句话 |
|---|---|
| DataFrame | 带列名和行索引的表格（Excel 的 Python 版） |
| 选择 | `df[列]` 选列、`df[条件]` 筛行 |
| groupby | 分组 + 聚合 = 实验对比表的核心 |
| 缺失值 | isna 统计、dropna 删、fillna 填 |
| DL 定位 | 元数据管理、结果整理；矩阵运算仍归 NumPy |

> pandas 一句话：**表格数据的组织者**。模型关心温度矩阵（NumPy），实验管理关心"哪批数据、什么环境、跑出什么指标"（pandas）。工业项目的可复现性一半靠 pandas 把元数据记清楚。
