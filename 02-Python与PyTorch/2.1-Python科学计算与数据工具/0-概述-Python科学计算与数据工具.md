## 这一节在深度学习中用在哪儿

深度学习是"用代码跑数学"。2.1 覆盖从**写 Python** 到**处理数据**的完整代码能力：

- **语法/函数/类/迭代器/with** → 看懂和写出训练脚本的基础
- **类型标注/异常/日志** → 训练脚本可维护、可诊断
- **NumPy** → 张量运算的底层引擎（PyTorch 的数学就是 NumPy 风格）
- **SciPy** → 滤波、插值、统计
- **pandas** → 表格、元数据、实验结果整理
- **Matplotlib/Seaborn** → 看懂数据、报告结果
- **scikit-learn** → 传统基线（PCA/SVM/指标）
- **OpenCV** → 图像预处理（对齐/滤波/形态学）
- **工程规范** → 配置、随机种子、目录、Git、环境
