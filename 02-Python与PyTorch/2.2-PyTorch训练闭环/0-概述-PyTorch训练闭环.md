## 这一节在深度学习中用在哪儿

2.1 学会了"处理数据"，2.2 学会"训练模型"——把数学（1 章）和代码（2.1）组合成可运行的训练闭环：

- **Tensor 与自动微分** → 模型的数学引擎（1.2.2 反向传播的落地）
- **Dataset/DataLoader** → 数据怎么喂给模型（2.1.3 生成器的应用）
- **nn.Module** → 模型怎么定义（2.1.2 类与魔术方法的应用）
- **损失/优化器/调度器** → 训练三件套（1.4 章的直接使用）
- **训练循环** → 把一切串起来的 10 行核心代码
- **checkpoint** → 训练成果的保存与恢复
- **GPU/混合精度** → 跑得快、省显存
- **Hook** → 看模型内部在想什么
- **单元测试** → 让训练代码可靠
