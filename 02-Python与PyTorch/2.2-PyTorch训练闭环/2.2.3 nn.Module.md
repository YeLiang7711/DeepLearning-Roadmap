**本节内容**：模型怎么定义——nn.Module（神经网络模块）的 forward 前向传播、参数管理、训练/评估模式切换。

> 属于：[[0-概述-PyTorch训练闭环|PyTorch 训练闭环]] > 2.2.3
> 掌握程度：**深入** — 所有模型都是 nn.Module 的子类

> **术语**：nn.Module（neural network Module）= 神经网络模块基类；forward（前向）= 输入怎么变成输出；parameter（参数）= 可训练权重；buffer（缓冲区）= 不训练但随模型保存的量（如 BatchNorm 的均值）；train/eval 模式 = 训练/评估模式切换。

---

## 先看一个例子：手写一个两层网络

2.1.2 讲过类与魔术方法——nn.Module 就是 PyTorch 给你写好的"模型基类"：

```python
import torch.nn as nn

class TwoLayerNet(nn.Module):
    """两层全连接网络（1.2.2 手算反向传播的那个例子）"""

    def __init__(self, in_dim=64, hidden_dim=128, out_dim=10):
        super().__init__()
        self.fc1 = nn.Linear(in_dim, hidden_dim)   # 第一层
        self.relu = nn.ReLU()                       # 激活
        self.fc2 = nn.Linear(hidden_dim, out_dim)   # 第二层

    def forward(self, x):
        """前向传播：输入 x → 输出 logits"""
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x

# 使用
model = TwoLayerNet()
logits = model(x)          # 注意：调 model(x)，不是 model.forward(x)
```

> **与 2.1.2 的连接**：`model(x)` 能直接调用就是因为 `__call__` 魔术方法——nn.Module 的 `__call__` 内部自动执行 `forward(x)` 并做检查（2.2.9 的 forward 计数、梯度管理等）。

---

## forward：只写"输入怎么变输出"

**forward 就是 1.2.2 计算图的代码版**——你只负责写前向，反向传播 backward() 自动完成：

```python
def forward(self, x):
    x = self.fc1(x)       # 线性变换（1.1.1 的 y = Wx + b）
    x = self.relu(x)      # 激活函数（1.2.4 速查表）
    x = self.fc2(x)
    return x
```

**要点**：
- 用 `self.fc1`、`self.relu` 等**子模块**组合——PyTorch 自动递归收集所有子模块的参数
- 不要在 forward 里改模型结构（创建新层要放 __init__）——不然每轮前向都会重新建层，参数丢失
- forward 里的中间变量不要存到 self（占显存）——局部变量即可

## 参数管理：parameters() / state_dict()

```python
# 所有可训练参数（递归收集所有子层的）
for name, param in model.named_parameters():
    print(name, param.shape)
# fc1.weight (128, 64)
# fc1.bias   (128,)
# fc2.weight (10, 128)
# fc2.bias   (10,)

# 参数量统计
total = sum(p.numel() for p in model.parameters())
# 128×64 + 128 + 10×128 + 10 = 9610 个参数

# state_dict：参数的名字 → 张量（保存/加载用，2.2.6）
state = model.state_dict()
model.load_state_dict(state)
```

| 方法 | 作用 |
|---|---|
| `model.parameters()` | 所有参数（给优化器，2.2.4） |
| `model.named_parameters()` | 参数 + 名字（调试） |
| `model.state_dict()` | 名字→张量 的字典（**保存模型用**） |
| `model.load_state_dict()` | 从字典恢复参数 |

> **与 1.1.1 的连接**：fc1.weight 就是矩阵 W，fc2.bias 就是 b——全连接层的数学（y = Wx + b）在 nn.Linear 里就是两个参数。

## 缓冲区（buffer）：不训练但要保存的量

有些量**不是参数**（不参与梯度更新）但要随模型保存——比如 BatchNorm 的均值/方差（03 章讲）：

```python
class MyModule(nn.Module):
    def __init__(self):
        super().__init__()
        self.register_buffer("running_mean", torch.zeros(64))
        # 不是 parameter（不会被优化器更新）
        # 但会出现在 state_dict() 里（保存/加载）

    def forward(self, x):
        self.running_mean = 0.9 * self.running_mean + 0.1 * x.mean(dim=0)
        return x
```

| | 参数（parameter） | 缓冲区（buffer） |
|---|---|---|
| 是否训练更新 | ✅ 是（优化器更新） | ❌ 否 |
| 是否保存 | ✅ | ✅ |
| 例子 | 权重、偏置 | BatchNorm 均值/方差 |

## train() / eval()：切换模型行为

```python
model.train()    # 训练模式：Dropout 生效、BatchNorm 用批统计
model.eval()     # 评估模式：Dropout 关闭、BatchNorm 用历史均值

# 训练循环里
model.train()
for batch in train_loader:
    ...  # 训练

# 验证/测试时
model.eval()
with torch.no_grad():    # 关梯度（省内存，2.2.6）
    for batch in val_loader:
        ...
```

**为什么必须切换**：
- **Dropout**（03 章）：训练时随机丢弃神经元防过拟合，评估时必须全用
- **BatchNorm**（03 章）：训练时用批内统计，评估时用累积的历史统计

**为什么没有 test() 模式**：测试和验证的模型行为完全一样（都关 Dropout、都用历史统计）——所以 PyTorch 只有 train/eval 两种模式，train/val/test 三阶段的区别在**数据**（喂哪批数据）不在**模式**：

```
model.train()           ← 训练阶段
for batch in train_loader: 训练...

model.eval()            ← 验证 + 测试共用
with torch.no_grad():
    for batch in val_loader:  验证...
    for batch in test_loader: 测试...   ← 同一个 eval()
```

> **最常见的 bug**：忘了 `model.eval()`——验证结果被 Dropout 的随机性污染，每次跑结果都不一样。训练循环模板（2.2.5）会固定这个习惯。

## 嵌套与组合：大模型 = 小模块的堆叠

```python
class BiggerNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.block1 = TwoLayerNet(64, 128, 64)   # 嵌套子模块
        self.head = nn.Linear(64, 2)

    def forward(self, x):
        return self.head(self.block1(x))

model = BiggerNet()
len(list(model.parameters()))   # 自动递归收集所有层参数
```

**模块嵌套是无限层的**——ResNet 就是几十个 Block 的嵌套（04 章），PyTorch 递归收集参数和保存。

## 总结

| 概念 | 一句话 |
|---|---|
| nn.Module | 模型基类：__init__ 定义层，forward 定义计算 |
| forward | 只写前向，反向自动（1.2.2 计算图） |
| parameters() | 所有可训练参数（给优化器） |
| state_dict | 名字→张量字典（保存/加载） |
| buffer | 不训练但保存（BatchNorm 统计量） |
| train()/eval() | 切换 Dropout/BatchNorm 行为（**常忘的 bug**） |
| 嵌套 | 大模型 = 小模块递归组合 |

> nn.Module 一句话：**定义"层"和"前向"，PyTorch 管"参数收集、反向传播、保存加载"**。写模型 = 在 __init__ 里堆层、在 forward 里写数据流——剩下的都是框架的活。
