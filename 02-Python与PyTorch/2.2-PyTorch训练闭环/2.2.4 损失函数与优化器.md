**本节内容**：训练三件套——损失函数（Loss）告诉模型"差多少"、优化器（Optimizer）告诉模型"怎么改"、调度器（Scheduler）控制"改多快"。

> 属于：[[0-概述-PyTorch训练闭环|PyTorch 训练闭环]] > 2.2.4
> 掌握程度：**会用** — 1.4 章优化理论的 PyTorch 落地

> **术语**：Loss（损失函数）= 衡量模型预测和真实值差距的函数；Optimizer（优化器）= 用梯度更新参数的算法；Scheduler（调度器）= 训练中自动调整学习率的组件；momentum（动量）= 惯性；weight decay（权重衰减）= L2 正则的工程实现。

---

## 先看一个例子：三件套怎么配合

```python
import torch.nn as nn
import torch.optim as optim

# 1. 损失函数：模型输出 vs 真实标签
criterion = nn.CrossEntropyLoss()

# 2. 优化器：拿着模型参数 + 学习率
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)

# 3. 调度器：训练中自动调学习率
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=50)

# 训练循环里（2.2.5 详讲）：
loss = criterion(model(batch), labels)   # 1. 算损失
optimizer.zero_grad()                    # 2. 清梯度
loss.backward()                          # 3. 算梯度
optimizer.step()                         # 4. 更新参数
scheduler.step()                         # 5. 调学习率
```

**三件套的分工**：损失函数回答"差多少"（[[1.3.4 最大似然估计与最大后验估计#最大似然估计|MLE]] 决定损失形式），优化器回答"怎么改"（[[1.4.1 梯度下降与随机梯度下降#梯度下降公式|梯度下降]]），调度器回答"改多快"（[[1.4.3 学习率、学习率调度与权重衰减#学习率调度：先大步后小步|学习率调度]]）。

## 损失函数（Loss）：常用速查

| 损失 | PyTorch 类 | 任务 | 对应原理 |
|---|---|---|---|
| 交叉熵 | `nn.CrossEntropyLoss()` | 多分类 | 交叉熵 = 类别分布 MLE |
| 二元交叉熵 | `nn.BCEWithLogitsLoss()` | 二分类 | MLE（伯努利） |
| 均方误差 | `nn.MSELoss()` | 回归 | MLE（高斯假设） |
| 平均绝对误差 | `nn.L1Loss()` | 回归（抗异常值） | 拉普拉斯假设 |
| Huber | `nn.SmoothL1Loss()` | 回归（稳健） | Huber 损失 |
| 自定义 | 自己写函数 | 任意 | 组合多个损失 |

> 对应原理：[[1.5.2 交叉熵#为什么分类损失用交叉熵|交叉熵]] · [[1.3.4 最大似然估计与最大后验估计#最大似然估计|MLE]] · [[1.3.4 最大似然估计与最大后验估计#补充：MAE 的拉普拉斯假设|拉普拉斯假设]] · [[1.3.6 稳健统计#Huber 损失|Huber 损失]]

```python
# CrossEntropyLoss 的坑：内部自带 Softmax！
# 模型的最后一层输出 logits（原始分数），不要自己再加 Softmax
loss = criterion(model(x), labels)   # labels 是整数索引，不是 one-hot

# 自定义损失：组合（比如 重建 + 梯度损失，12 章 AE 用）
def my_loss(pred, target):
    mse = nn.functional.mse_loss(pred, target)
    grad_loss = nn.functional.mse_loss(gradient(pred), gradient(target))
    return mse + 0.5 * grad_loss
```

> CrossEntropyLoss 就是 [[1.5.2 交叉熵|交叉熵]]——负 log 正确类别概率。损失形式不是随便选的，是分布假设下的 [[1.3.4 最大似然估计与最大后验估计#最大似然估计|MLE]]（[[1.3.4 最大似然估计与最大后验估计#MSE / MAE 与 MLE / MAP 的完整关系图|1.3.4 的表格]]直接对应）。

## 优化器（Optimizer）：常用速查

| 优化器 | 类 | 特点 | 典型场景 |
|---|---|---|---|
| SGD | `optim.SGD` | 基础（可加 momentum） | 经典 CNN、微调 |
| Adam | `optim.Adam` | 自适应步长 | 快速原型 |
| **AdamW** | `optim.AdamW` | Adam + 正确权重衰减 | **现代默认** |

```python
# 最常用配置
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)

# SGD + momentum（CV 微调常见）
optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9, weight_decay=5e-4)
```

| 参数 | 含义 | 来源 |
|---|---|---|
| `lr` | 学习率（最重要的超参数） | 1.4.3 学习率 |
| `momentum` | 惯性系数 | 1.4.2 Momentum |
| `weight_decay` | 权重衰减 = L2 正则 | 权重衰减，MAP |

> 来源：[[1.4.3 学习率、学习率调度与权重衰减#学习率：训练里最重要的超参数|1.4.3 学习率]] · [[1.4.2 Momentum、Adam、AdamW#Momentum|1.4.2 Momentum]] · [[1.4.3 学习率、学习率调度与权重衰减#权重衰减|权重衰减]] · [[1.3.4 最大似然估计与最大后验估计#最大后验估计|MAP]]

> [[1.4.2 Momentum、Adam、AdamW#AdamW|AdamW]] 是"炼丹默认"——Transformer/现代模型标配（[[1.4.2 Momentum、Adam、AdamW#AdamW|解耦权重衰减]]的原理）。

## 调度器（Scheduler）：自动调学习率

```python
# Cosine 衰减（现代默认，[[1.4.3 学习率、学习率调度与权重衰减#学习率调度：先大步后小步|学习率调度]]讲过）
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=epochs)

# Step 衰减（每 30 轮 ×0.1，经典 CNN）
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)

# 自定义：Warmup + Cosine（大模型标配）
def warmup_cosine(epoch):
    if epoch < 5:
        return epoch / 5                    # 前 5 轮线性升
    return 0.5 * (1 + cos(pi * (epoch - 5) / (epochs - 5)))
scheduler = optim.lr_scheduler.LambdaLR(optimizer, lr_lambda=warmup_cosine)
```

> 图 1.4.3-2（Warmup + Cosine 曲线）就是这段代码画出来的——先大步稳定、再平滑衰减（见 [[1.4.3 学习率、学习率调度与权重衰减#学习率调度：先大步后小步|学习率调度]]）。

## 总结

| 概念 | 一句话 |
|---|---|
| 损失函数 | 衡量"差多少"——形式由分布假设决定（MLE） |
| CrossEntropyLoss | 分类默认，内部自带 Softmax（别再手动加） |
| 优化器 | 用梯度更新参数——AdamW 是默认 |
| 调度器 | 训练中自动调学习率（Cosine/Warmup） |
| 三件套 | 损失算差距、优化器改参数、调度器调速 |
| 理论落地 | 1.4 章每个概念 = 这里一行 API |

> 三件套一句话：**损失说"差多少"、优化器说"怎么改"、调度器说"改多快"**——1.4 章的优化理论在这里变成三行代码，配上 2.2.5 的训练循环就是完整的训练系统。
