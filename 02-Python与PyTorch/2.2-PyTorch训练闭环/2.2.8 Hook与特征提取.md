**本节内容**：看模型"内部在想什么"——Hook（钩子）在 forward/backward 时插入自定义逻辑，提取中间特征、可视化、调试。

> 属于：[[0-概述-PyTorch训练闭环|PyTorch 训练闭环]] > 2.2.8
> 掌握程度：**会用** — 模型可视化和调试的核心工具

> **术语**：Hook（钩子）= 注册在层上的回调函数，层被调用时自动触发；feature map（特征图）= 卷积/线性层的中间输出；forward hook = 前向时触发；backward hook = 反向时触发。

---

## 为什么需要 Hook：模型是个黑箱

模型内部每层都产生中间结果（特征图），但训练/推理代码只接触输入和输出。**想看看"卷积层提取了什么特征"** 怎么办？

- ❌ 改模型代码在中间加 return——破坏结构、侵入式
- ✅ **Hook**：不动模型代码，从外部"挂"个回调，层被调用时自动拿到中间结果

> **与 2.2.3 的连接**：模型是层组成的（nn.Module 嵌套），Hook 挂在具体层上——不需要改 forward。

---

## register_forward_hook：提取中间特征

```python
# 准备一个容器存特征
features = {}

def hook_fn(module, input, output):
    """每当前向经过该层，自动调用：module=层, input=输入, output=输出"""
    features[module] = output.detach().cpu()   # detach 断开计算图（省显存）

# 在某一层上注册 hook
handle = model.layer3.register_forward_hook(hook_fn)

# 正常前向——hook 自动触发
_ = model(x)
print(features[model.layer3].shape)   # 该层的特征图

# 用完移除（防内存泄漏/干扰）
handle.remove()
```

**hook 函数三参数**：`module`（哪层）、`input`（层输入）、`output`（层输出）——你只关心 output（特征图）。

---

## 提取多层特征：一个 hook 收集全部层

```python
features = {}
handles = []

def make_hook(name):
    def hook_fn(module, input, output):
        features[name] = output.detach().cpu()
    return hook_fn

# 给多层注册（名字 → 输出）
for name, layer in model.named_modules():
    if isinstance(layer, (nn.Conv2d, nn.Linear)):   # 只挂卷积/线性层
        handles.append(layer.register_forward_hook(make_hook(name)))

# 前向一次，收集所有层的特征
_ = model(x)
for name, feat in features.items():
    print(name, feat.shape)    # 每层的特征图 shape

# 用完清理
for h in handles:
    h.remove()
```

> **与 8 章迁移学习的连接**：不同层提取不同粒度的特征——浅层是纹理/边缘、深层是语义（路线图 8. 迁移学习与深度特征）。Hook 就是"提取任意层特征"的标准工具。

## 特征可视化：看模型学到了什么

```python
import matplotlib.pyplot as plt

# 取某一卷积层的输出（如 64 个通道的特征图）
feat = features["features.0"]        # (B, 64, H, W)
grid = feat[0][:16]                  # 第一个样本的前 16 个通道

# 画成 4×4 网格
fig, axes = plt.subplots(4, 4, figsize=(8, 8))
for ax, channel in zip(axes.flatten(), grid):
    ax.imshow(channel, cmap="hot")   # 温度风格
    ax.axis("off")
plt.savefig("feature_maps.png")
```

**看什么**：
- **浅层**：边缘、纹理、热点位置（"看到了什么结构"）
- **深层**：语义激活（"关注什么概念"）——异常检测里可以看到模型是否真的聚焦缺陷区域

> **与 1.3.3 图注的连接**：热图可视化就是 2.1.6 的 imshow——特征图本质是二维数组。

## 用途盘点

| 用途 | 怎么做 |
|---|---|
| **特征可视化** | forward hook 收集 → 画热图 |
| **特征提取**（下游任务） | 冻结模型 + hook 取特征 → 喂给 PCA/kNN |
| **调试** | 看中间层是否有 NaN/全零（层死掉了） |
| **正则化/自定义损失** | hook 拿中间特征参与损失计算（感知损失，12 章 AE） |
| **注意力可视化** | 对 Transformer 层取 attention 权重 |

> **与 11-异常检测的连接**：特征提取是 PatchCore/PaDiM 的第一步——用预训练模型 + hook 提取 patch 特征，再建记忆库/高斯建模（12-工业异常检测展开）。

## backward hook：看梯度流向

```python
def grad_hook(module, grad_input, grad_output):
    """反向经过该层时触发：grad_output 是这一层的梯度"""
    print(module, "梯度范数:", grad_output[0].norm().item())

handle = model.fc1.register_full_backward_hook(grad_hook)

loss.backward()    # 自动触发
```

**用途**：
- 检查**梯度消失**：深层梯度范数极小（RNN 常见）
- 检查**梯度爆炸**：范数超大（1.4.2 讲过）

> **与 1.2.2 的连接**：backward hook 让你"看到"反向传播每层乘了多少——链式法则的梯度在流动中可视化。

## 总结

| 概念 | 一句话 |
|---|---|
| Hook | 挂在层上的回调，前向/反向时自动触发 |
| forward hook | 拿中间特征图（可视化/提取/调试） |
| 特征可视化 | 浅层纹理、深层语义（8 章连接） |
| 特征提取 | 冻结模型 + hook → 下游 PCA/kNN |
| backward hook | 看梯度流动（消失/爆炸诊断） |
| 清理 | 用完 `handle.remove()`（防泄漏） |

> Hook 一句话：**不改模型代码，从外部"偷看"模型的内部**——特征可视化、特征提取、梯度诊断都是它的活。看完内部，下一步把它变成工程（2.2.9 测试）。
