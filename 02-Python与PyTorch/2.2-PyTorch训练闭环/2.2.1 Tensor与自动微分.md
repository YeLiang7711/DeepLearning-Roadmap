**本节内容**：Tensor 是"带自动微分的 NumPy 数组"——dtype/shape/device 三大属性 + requires_grad/backward 自动算梯度。

> 属于：[[0-概述-PyTorch训练闭环|PyTorch 训练闭环]] > 2.2.1
> 掌握程度：**深入** — 训练循环的心脏

> **术语**：Tensor = 张量，同一个东西。Tensor 是 PyTorch 的类名（代码里这么写），张量是中文数学术语（1.1.1 讲过：标量/向量/矩阵/张量是逐级升维的数组）。PyTorch 里"Tensor"特指"多维数组 + 自动微分"的那个对象。

---

## 先看一句话

> **Tensor = NumPy 数组 + 自动微分。**

2.1.3 学的 NumPy 运算（shape、索引、广播）在 Tensor 上几乎一样用；多出来的核心能力是 **backward()**——一次调用算出所有梯度（1.2.2 反向传播的落地）。

```python
import torch

# 创建张量（和 NumPy 几乎一样）
x = torch.tensor([1.0, 2.0, 3.0])
a = torch.zeros(2, 3)
b = torch.randn(100, 100)          # 标准正态（1.3.3 的分布）
c = torch.arange(10)

# 运算（广播规则与 NumPy 相同，2.1.3）
y = a + 2.0
z = x @ torch.randn(3, 5)          # 矩阵乘法
```

## 三大属性：dtype / shape / device

| 属性 | 作用 | 常见值 | 坑 |
|---|---|---|---|
| **dtype** | 数据类型（精度） | float32（默认）、float64、int64 | 混用会报错或自动转换 |
| **shape** | 维度结构 | (B,C,H,W)、(N,D) | 90% 报错来自 shape 不匹配 |
| **device** | 在哪计算 | cpu、cuda:0 | CPU/GPU 张量不能直接运算 |

```python
x = torch.randn(2, 3)
x.dtype        # torch.float32
x.shape        # torch.Size([2, 3])
x.device       # device(type='cpu')

# 转换
x.float() / x.double()          # 改精度
x.to("cuda") / x.cuda()         # 挪到 GPU
x.cpu() / x.numpy()             # 回 CPU / 转 NumPy
torch.from_numpy(np_array)      # NumPy → Tensor
```

> **调试第一步永远是这三个**：报错先打印 `x.shape, x.dtype, x.device`——十个错误九个出在这里。

## 自动微分：requires_grad 与 backward

### 追踪计算过程

```python
# 一个简单计算：y = x² + 2（对标 1.2.1 的导数例子）
x = torch.tensor(3.0, requires_grad=True)   # 告诉 PyTorch：我要 x 的梯度
y = x ** 2 + 2                               # 前向：PyTorch 记录计算图

y.backward()                                 # 反向：自动算 dy/dx
x.grad                                       # tensor(6.) —— 2x = 2×3 ✓
```

**验证**：$\frac{dy}{dx} = 2x = 6$——和 1.2.1 手算结果一致。

### 计算图：PyTorch 记住"怎么算出来的"

```
x (requires_grad=True)
  │
  ├─→ [x²] ─→ [x²+2] ─→ y
  │                    │
  └─ backward() 沿图反向传播
     每个节点乘上"当地导数"（1.2.2 的链式法则）
```

### 神经网络里的典型用法

```python
w = torch.randn(4, 1, requires_grad=True)   # 权重（1.4.1 的参数）
loss = ((x @ w - y_true) ** 2).mean()       # 前向：算损失
loss.backward()                             # 反向：w.grad 自动填好
# w.grad 就是 ∂loss/∂w —— 交给优化器更新（2.2.4/2.2.5）
```

### 关键细节

| 细节 | 说明 |
|---|---|
| `requires_grad=False`（默认） | 不需要梯度的张量（数据、标签） |
| `with torch.no_grad():` | 推理时关梯度（2.2.6），省内存 |
| `.detach()` | 从计算图断开（当常数用） |
| `x.grad.zero_()` | 清空梯度（2.2.5 每步训练前必做） |
| 叶子节点 | 只有直接创建的张量有 `.grad`（中间量没有） |

> **和 1.2.2 的连接**：backward() 就是自动版的反向传播——PyTorch 帮你把链式法则乘到底，你只管写前向代码。

## Tensor vs NumPy 完整对照

| 操作 | NumPy | PyTorch Tensor |
|---|---|---|
| 创建 | np.array / zeros / randn | torch.tensor / zeros / randn |
| shape | a.shape | a.shape |
| 变形 | a.reshape(-1) | a.view(-1) / a.reshape(-1) |
| 矩阵乘 | a @ b | a @ b |
| 均值 | a.mean() | a.mean() |
| 随机 | np.random.randn | torch.randn |
| 互转 | — | torch.from_numpy / .numpy() |

**区别**：
- Tensor 多了自动微分（requires_grad/backward）
- Tensor 可以在 GPU 上算（NumPy 不行）
- 广播、索引、切片规则相同（2.1.3 的知识直接迁移）

---

## 总结

| 概念 | 一句话 |
|---|---|
| Tensor | NumPy 数组 + 自动微分 |
| dtype/shape/device | 精度 / 结构 / 位置——调试第一检查项 |
| requires_grad | 告诉 PyTorch"这个张量要梯度" |
| backward() | 一次调用算完所有梯度（1.2.2 落地） |
| 计算图 | PyTorch 记住前向过程，反向按图乘链式法则 |
| no_grad/detach | 推理断开、常数化 |

> Tensor 一句话：**NumPy 的语法 + 自动微分的引擎**。写前向代码时像写 NumPy，backward() 一次把梯度全算好——1.2.2 手算的反向传播从此交给 PyTorch。
