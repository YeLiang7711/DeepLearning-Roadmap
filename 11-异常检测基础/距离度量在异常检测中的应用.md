## 欧氏距离在 PatchCore 中的应用

PatchCore 的核心操作：用正常样本的 patch 特征建一个**记忆库**，对新样本的每个 patch 在记忆库中找最近邻。

```
测试图像的第 j 个 patch 特征 → 在记忆库中找欧氏距离最近的 k 个正常 patch
                                    ↓
                           距离越近 → 越像正常 → 异常分数低
                           距离越远 → 不像正常 → 异常分数高
```

对于测试 patch 特征 $\mathbf{p}_{\text{test}}$ 和记忆库 $\mathcal{M}$：
$$s(\mathbf{p}_{\text{test}}) = \min_{\mathbf{m} \in \mathcal{M}} \|\mathbf{p}_{\text{test}} - \mathbf{m}\|_2$$

欧氏距离的隐含假设——各维度独立等方差——在高维深度特征中通常不严格成立，但因为特征空间足够大、近邻数量够多，实践中 kNN 方法效果仍然很好。

## Mahalanobis 距离在异常检测中的应用

### 问题场景

假设检测系统提取了两个特征维度：**温度** 和 **梯度**。正常样本中，温度和梯度**正相关**（高温区通常伴随大梯度）：

```
梯度 ↑
     │    ···
     │   ·····
     │    ···
     │     ·
     └──────────→ 温度
```

数据呈**椭圆形**分布，长轴沿对角线方向。

来了两个测试点：

| 点 | 温度 | 梯度 | 位置 | 实际 |
|---|---|---|---|---|
| **A** | 比均值高 3°C | 也比均值高 | 沿对角线，在椭圆长轴上 | 挺正常的 |
| **B** | 正常 | 极高 | 偏离对角线，椭圆外面 | **很可能是异常** |

欧氏距离只画圆：A 离中心绝对距离大 → 判异常；B 离中心近 → 判正常。**判反了。**

### Mahalanobis 怎么纠正

$\mathbf{\Sigma}^{-1}$ 把相关维度"拉正"：协方差分解 $\mathbf{\Sigma} = \mathbf{V}\mathbf{\Lambda}\mathbf{V}^\top$，则 $D_M = \|\mathbf{\Lambda}^{-1/2} \mathbf{V}^\top (\mathbf{x}-\boldsymbol{\mu})\|_2$，即旋转到主轴上 → 各方差归一化 → 再算欧氏距离。

| | 温度维度 | 梯度维度 | 相关性 |
|---|---|---|---|
| 正常数据 | 方差大（±3°C 波动属于正常） | 方差中等 | 正相关 |
| $\mathbf{\Sigma}^{-1}$ 效果 | 沿对角线（正常变化方向）→ 宽容 | 垂直对角线（异常方向）→ 收紧 | 椭圆→圆 |

- 点 A 沿对角线偏移 → 落在"正常主轴"上 → $D_M$ 不大 → ✅ 判正常
- 点 B 垂直偏离对角线 → 正常数据极少去的方向 → $D_M$ 放大 → ✅ 判异常

### 在 PaDiM 中的实际使用

PaDiM 为特征图的**每个空间位置** $(h,w)$ 单独估计一个多元高斯分布：

$$\mathbf{x}_{h,w} \sim \mathcal{N}(\boldsymbol{\mu}_{h,w}, \mathbf{\Sigma}_{h,w})$$

该位置的异常分数：
$$s_{h,w} = \sqrt{(\mathbf{x}_{h,w} - \boldsymbol{\mu}_{h,w})^\top \mathbf{\Sigma}_{h,w}^{-1} (\mathbf{x}_{h,w} - \boldsymbol{\mu}_{h,w})}$$

每个位置有**自己的协方差矩阵**，意味着：

- **边缘区域**：正常就有大波动 → $\mathbf{\Sigma}$ 特征值大 → 容忍度高
- **核心测温区**：正常很稳定 → $\mathbf{\Sigma}$ 特征值小 → 轻微偏差就报警

这就是为什么 Mahalanobis 比固定阈值或欧氏距离更适合工业检测——**每个位置都有自己的"正常标准"**。
