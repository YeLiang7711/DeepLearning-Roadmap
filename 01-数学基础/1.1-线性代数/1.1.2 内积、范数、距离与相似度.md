## 内积（点积）— 衡量"有多配"的数字

### 先忘掉公式，看一个例子

你去超市买了 3 样东西：

| 商品 | 单价 | 你买的数量 |
|---|---|---|
| 可乐 | 5 元 | 2 瓶 |
| 薯片 | 8 元 | 1 包 |
| 面包 | 3 元 | 4 个 |

**总价怎么算？**

```
5×2 + 8×1 + 3×4 = 10 + 8 + 12 = 30 元
```

这就是内积。把两个向量——**单价** `[5, 8, 3]` 和**数量** `[2, 1, 4]`——对应位置相乘再加起来，得到一个数：30。

内积的本质是：**你有两排数字，按位相乘再求和，得到一个"匹配总分"。**

### 公式（回头看就清楚了）

$$\mathbf{a} \cdot \mathbf{b} = a_1b_1 + a_2b_2 + \cdots + a_nb_n$$

### 几何画面

内积还有一个重要的几何含义：

$$\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}| \times |\mathbf{b}| \times \cos\theta$$

翻译：**两向量长度 × 夹角余弦**。

想象两个人拉一根绳子：

```
→→→→→  ← 两人拉同一个方向  → cosθ=1  → 内积最大（完全合力）
→  ↑   ← 一人横拉一人竖拉 → cosθ=0  → 内积为 0（各拉各的，互不影响）
→  ←  ← 两人反方向拉    → cosθ=-1 → 内积为负（互相抵消）
```

所以内积的正负大小，本质上是在问：**这两个向量在多大程度上指向同一个方向？**

### 为什么深度学习到处用它

**场景一：全连接层**

一张温度图有 $64 \times 64 = 4096$ 个像素，展平成一个 4096 维向量 $\mathbf{x}$。我们要判断图里有没有异常，输出"正常 vs 异常"两个分数。

从 4096 个数 → 2 个分数，不能一步到位跳跃太大，需要一个中间层来逐步提取特征。

**中间层设多少个神经元？这没有规定，是工程师自己选的。**

```
输入层(4096) → 隐藏层(自己选，比如512) → 输出层(2)
```

选择多少取决于：

| 考虑因素 | 多了会怎样 | 少了会怎样 |
|---|---|---|
| 任务复杂度 | 简单任务浪费算力 | 复杂模式学不会 |
| 数据量 | 参数太多→数据不够→过拟合 | 参数太少→欠拟合 |
| 输入大小 | 相对 4096 输入，512 是合理压缩 | 压缩太狠丢失信息 |
| 经验习惯 | 通常用 2 的幂次：128/256/512/1024 | — |

> **512、256、128 这些数字不是谁规定的，只是大家习惯用 2 的幂次（GPU 对 2 的幂次运算更高效）。也可以用 300、777、1000，没人拦着。**

**每个神经元在做什么？**

拿隐藏层 512 个神经元中的第 3 号神经元举例：

```
         权重                    输入
z₃ = [w₃,₁, w₃,₂, ..., w₃,₄₀₉₆] · [x₁, x₂, ..., x₄₀₉₆]  + b₃
     └──────── 4096 个权重 ────────┘   └─ 4096 个像素 ─┘
                     ↑ 内积！                         ↑
```

$$z_i = \mathbf{w}_i \cdot \mathbf{x} + b_i = \sum_{j=1}^{4096} w_{i,j} \, x_j + b_i$$

一个神经元 = 一次内积 + 一个偏置。
512 个神经元 = 并行 512 次内积。

**可以想象成**：512 个裁判，每人手里有一套 4096 项的评分标准（权重），他们同时给同一张图打分。有人关注"左上角温度高不高"，有人关注"中间有没有突变点"，有人关注"整体是不是太冷"。最后综合 512 个裁判的意见，得出"正常还是异常"的结论。

**场景二：Attention — 最重要的应用**

你读一句话："今天 天气 很好"。你的大脑自动在判断每个词和其他词的关联：

```
"天气"和"好"关系很强     ← "好"是在修饰"天气"
"今天"和"天气"关系中等   ← "今天"限定了时间范围
"今天"和"好"关系很弱     ← 它们没有直接修饰关系
```

Attention 做的就是这件事。每个词用三个向量表示：

- **Query（查询）**："我在找什么相关信息？"
- **Key（键）**："我是什么内容？"
- **Value（值）**："我携带的实际信息"

"天气"的 Query 和每个词的 Key 做内积：

```
"天气"Q · "今天"K = 0.3   ← 有一定关系
"天气"Q · "天气"K = 7.2   ← 自己和自己，关系最强
"天气"Q · "很好"K = 6.8   ← 修饰关系，关系很强
```

内积分数 → Softmax 变成权重 → 用权重加权求和 Value → 每个词融入了上下文信息。

**一整个 Attention 层就是海量内积运算。** 公式里那个 $QK^\top$ 就是一次性算了所有 Query 和所有 Key 之间的内积。

### 一句话总结

> 内积 = 对应相乘再求和 = 一个衡量"两个东西有多配"的数字。在 DL 里，全连接层用它做线性变换，Attention 用它判断词与词之间的关联。

## 范数：衡量"大小"

| 范数 | 公式 | 直观 |
|---|---|---|
| **L1 范数** | $\|\mathbf{x}\|_1 = \sum_i \|x_i\|$ | 曼哈顿距离，走直角 |
| **L2 范数** | $\|\mathbf{x}\|_2 = \sqrt{\sum_i x_i^2}$ | 直线距离，勾股定理推广 |
| **Frobenius 范数** | $\|\mathbf{A}\|_F = \sqrt{\sum_{i,j} A_{ij}^2}$ | 矩阵看作长向量后的 L2 |

L2 正则化（权重衰减）：
$$\mathcal{L}_{\text{reg}} = \mathcal{L}_{\text{task}} + \lambda \|\mathbf{w}\|_2^2$$

## 距离与相似度

### 1. 欧氏距离

$$d(\mathbf{a},\mathbf{b}) = \|\mathbf{a} - \mathbf{b}\|_2 = \sqrt{\sum_{i=1}^{n}(a_i - b_i)^2}$$

两点之间的直线距离。**隐含假设**：每个维度同等重要，各维度之间相互独立。

### 2. 余弦相似度

$$\cos(\mathbf{a},\mathbf{b}) = \frac{\mathbf{a}^\top \mathbf{b}}{\|\mathbf{a}\| \, \|\mathbf{b}\|} = \cos\theta$$

取值范围 $[-1, 1]$。只看方向，不看长度。

> 两张温度图，一张整体偏高 2°C 一张偏低 1°C，分布形状相同 → 余弦相似度高（结构相似），欧氏距离大（绝对值不同）。

归一化后（$\|\mathbf{f}\|_2 = 1$），欧氏距离与余弦相似度等价：
$$\|\mathbf{a} - \mathbf{b}\|^2 = 2 - 2\cos(\mathbf{a},\mathbf{b})$$

### 3. Mahalanobis 距离

$$D_M(\mathbf{x}) = \sqrt{(\mathbf{x} - \boldsymbol{\mu})^\top \mathbf{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})}$$

**解决了欧氏距离什么问题？**

欧氏距离假设各维度独立且等方差 → 画的是一个**正圆**。但真实数据各维度之间往往有相关性且方差不同 → 数据呈**椭圆**分布。

$\mathbf{\Sigma}^{-1}$ 的作用是把椭圆"拉正"成圆，然后再算欧氏距离。

**数学上怎么做到的**：对协方差矩阵做特征分解 $\mathbf{\Sigma} = \mathbf{V} \mathbf{\Lambda} \mathbf{V}^\top$：

$$\mathbf{\Sigma}^{-1} = \mathbf{V} \mathbf{\Lambda}^{-1} \mathbf{V}^\top$$

代入得：
$$D_M(\mathbf{x}) = \left\| \mathbf{\Lambda}^{-1/2} \mathbf{V}^\top (\mathbf{x} - \boldsymbol{\mu}) \right\|_2$$

展开就是三步：

```
(x - μ) → 步骤1: Vᵀ 旋转到主轴上
       → 步骤2: Λ^{-1/2} 各方向除以正常波动（方差大→除以大→放宽，方差小→除以小→收紧）
       → 步骤3: ‖·‖₂ 在拉正后的空间算欧氏距离
```

> 关键直觉：**Mahalanobis 距离 = 在"数据说了算"的坐标系里算欧氏距离**。哪一维正常波动大，就宽容；哪一维正常很稳定，就严格。

### 三者对比

| | 欧氏距离 | 余弦相似度 | Mahalanobis 距离 |
|---|---|---|---|
| 看什么 | 绝对差值 | 方向/夹角 | 相对分布的偏离 |
| 几何 | 正圆 | 单位球面的角度 | 拉正后的圆（原空间是椭圆） |
| 需要什么 | 无 | 无 | $\boldsymbol{\mu}$ 和 $\mathbf{\Sigma}$ |
| 对噪声 | 敏感 | 只对方向敏感 | 考虑正常波动范围 |
