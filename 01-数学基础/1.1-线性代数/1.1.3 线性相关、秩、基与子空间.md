# 1.1.3 线性相关、秩、基与子空间

> 属于：[[0-概述|线性代数]] > 1.1.3
> 掌握程度：**了解** — 这三个概念是理解"数据有多少冗余"和 PCA 降维的前提

---

## 一句话说清这三个东西的关系

这三个概念回答的是同一个核心问题：

> **"我手里的数据，到底有多少是真正独立的信息？"**

- **线性相关** → 找冗余：哪些信息其实是同一条信息换了个说法？
- **秩** → 数独立信息：剥掉冗余后，还剩几个真正独立的维度？
- **基与子空间** → 用最少的砖盖房子：用几个独立维度就能表示所有数据？

---

## 线性相关 — "有人在摸鱼"

### 先说人话

你让三个朋友去测同一间房的温度：

| 朋友 | 报告的值 | 怎么算的 |
|---|---|---|
| 小明 | 25°C | 直接读数 |
| 小红 | 25°C | 直接读数（另一个温度计） |
| 小刚 | 30°C | 他每次都在读数上 +5°C |

小刚的数据等于"小明 + 5"，这是完全可预测的——他就是小明的数据换了个说法。

**小刚的信息是冗余的。** 这就是线性相关：一组数据里，有的能被其他数据的组合完全表示出来。

### 形式化（回头看就懂了）

三个向量 $\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3$：

$$\mathbf{v}_3 = \mathbf{v}_1 + 5$$

移项：$$\mathbf{v}_3 - \mathbf{v}_1 - 5\cdot \mathbf{1} = \mathbf{0}$$

存在一组不全为零的系数，使得加权和为 0 → 线性相关。

### 温度场里的实际例子

100×100 温度图，相邻像素的温度通常是渐变的：

```
[25.1] [25.2] [25.3] ...
[25.2] [25.3] [25.4] ...
[25.3] [25.4] [25.5] ...
```

右边像素 ≈ 左边像素 + 0.1。虽然这张图有 10000 个像素，但绝大多数像素可以从邻居推算出来。**像素之间高度线性相关**——这就是为什么一张图可以压缩到很小还能看清。

## 秩 — "到底有几个干活的人"

### 接上面的例子

三个朋友测温，去掉摸鱼的小刚，真正独立的信息来源只有：

- 小明（直接读数）— 独立来源 1
- 小红（另一个温度计，略有误差）— 独立来源 2

小刚 = 小明 + 5，不独立。

**秩 = 2**。虽然有三个人，但只有两个"真正不同的信息"。

### 公式

$$\text{rank}(\mathbf{A}) = \text{最大线性无关的列数（或行数）}$$

### 直觉：一张温度图有多少"独立信息"？

100×100 的温度图 = 10000 个数字。但它的秩是多少？

- 如果图完全是均匀的 25°C → 秩 = 1（只需要一个数"25"就能描述整张图）
- 如果图是平滑的温度场（大部分情况）→ 秩很小，可能只要几十
- 如果图有大量随机噪声 → 秩接近 10000

**秩告诉你：数据本质上有多复杂。** 秩小 = 数据简单低维 = 可以大幅压缩不丢信息。

### 深度学习里秩决定了两件事

**第一件：为什么 PCA 能降维**

如果 10000 像素的温度图的秩 ≈ 20，那就只需要 20 个主成分就能几乎无损还原 → PCA 就干这个。

**第二件：协方差矩阵为什么有时候求不了逆**

统计协方差矩阵 $\mathbf{\Sigma}$ 的时候，如果样本数太少（比如只有 100 张图），矩阵的秩 ≤ 100。但特征维度可能有 10000。

不满秩 → 行列式为 0 → 没有逆矩阵 → 需要加一个正则化项：

$$\hat{\mathbf{\Sigma}}^{-1} \approx (\mathbf{\Sigma} + \lambda \mathbf{I})^{-1}$$

这就是"shrinkage"——加一点噪声让矩阵满秩，保证可逆。

## 基与子空间 — "用最少的砖盖房子"

### RGB：每个人每天都用的基

你的屏幕显示所有颜色，但只需要三根"电子枪"：红、绿、蓝。

```
任何颜色 = (R分量) × 红色 + (G分量) × 绿色 + (B分量) × 蓝色
```

- **基** = {红, 绿, 蓝}，三个独立的基础色
- **子空间** = 红绿蓝能混合出的所有颜色（= 你屏幕能显示的所有颜色）

三个基向量就能张成一个巨大的空间（1670 万种颜色），因为你可以任意调节三个分量的数值。

### 温度场的基

一张正常的温度图，可以拆成几个"基础模式"的叠加：

```
温度图 ≈ a₁ × (整体均值模式)
       + a₂ × (左高右低模式)
       + a₃ × (中心热点模式)
       + a₄ × (边缘降温模式)
       ...
```

这组"基础模式"就是**基**。所有的正常温度图都落在这些基张成的**子空间**里。

### 异常检测的直觉

> **正常数据落在子空间内，异常数据跑到子空间外。**

这就是 PCA 做异常检测的底层逻辑：用正常数据学一个低维子空间，新样本投影上去，投影不上去的部分（残差）就是异常信号。

### 公式

选了 $k$ 个基向量 $\{\mathbf{v}_1, \dots, \mathbf{v}_k\}$（$k$ = 秩），任意落在子空间里的数据可以唯一表示为：

$$\mathbf{x} = \alpha_1 \mathbf{v}_1 + \alpha_2 \mathbf{v}_2 + \dots + \alpha_k \mathbf{v}_k$$

$\alpha_i$ 就是在问"这个模式占了多少"。

## 三个概念串起来

```
线性相关：小刚 = 小明 + 5  →  小刚是冗余的，踢掉
            ↓
秩：    剩下小明和小红 → 秩 = 2，真正独立的只有俩
            ↓
基：    {小明, 小红} 就是基 → 任何温度数据都能表示为
        "小明的读数 × a + 小红的读数 × b"
            ↓
子空间：a 和 b 随意取，得到的所有结果 → 正常温度的范围
        跑出这个范围的 → 异常
```

> **线性相关告诉你谁在摸鱼，秩数一下还剩几个干活的，基是干活的骨干队伍，子空间是这群人能盖出的所有房子。**
