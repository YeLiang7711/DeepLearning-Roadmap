**本节内容**：特征向量是"方向不变只缩放"的方向，SVD 把任意矩阵拆成旋转-拉伸-旋转三步。

> 属于：[[0-概述-线性代数|线性代数]] > 1.1.4
> 掌握程度：**会用** — 重点是理解"SVD 把矩阵拆成三块"这个画面

---

## 先搞清楚我们在解决什么问题

矩阵 $\mathbf{A}$，你可以把它看成一个"变形机器"：

```
                                     →
输入一个向量 x  ──→  [ 矩阵 A ]  ──→ 输出向量 Ax
                                     →
```

矩阵乘向量，就是把输入向量**旋转 + 拉伸**变成另一个向量。

现在问题来了：

> **有没有一些特殊的输入方向，经过矩阵后方向完全不变，只是被拉长或缩短了？**

---

## 特征值与特征向量

### 还是先看例子

一个变换：把正方形变成平行四边形。

```
  输入空间                    输出空间
  ┌────┐                    ╱‾‾‾‾╱
  │    │   →  矩阵A  →     ╱     ╱
  └────┘                  ╱_____╱    ← 被斜着压扁了
```

大部分向量进去，方向都变了。但是……

```
     ↗ 这个方向上的向量                    ↗ 方向不变！
    /   进去之后只是变长了                 /  只是长度变了
   /                                    /

            但 ↘ 那个方向上的向量                  ↘ 方向也变了
                → 进去就歪了
```

**那两个方向不变的，就是特征向量；变长/变短的倍数，就是特征值。**

### 公式（回头看就清楚了）

$$\mathbf{A}\mathbf{v} = \lambda \mathbf{v}$$

- $\mathbf{v}$ = 特征向量，方向保持不变的那个方向
- $\lambda$ = 特征值，放大的倍数

### 物理类比：铁板传热

一块铁板，左边加热，右边冷却。温度在铁板上形成稳定分布。

用矩阵描述每个位置的温度变化。**特征向量就是温度分布的基本模式**，特征值就是每种模式的衰减速度。

- $\lambda_1 = 0.95$（最大特征值）→ 模式 1 衰减最慢 → 主导长期温度分布
- $\lambda_{10} = 0.01$（小特征值）→ 模式 10 几乎瞬间消失 → 对结果影响很小

**这就是 PCA 选择"保留前几个最大特征值"的直觉来源——特征值大的方向，才是数据真正的主旋律。**

### 用温度图直观看

一张 100×100 的温度图，可以看作 10000 个特征向量叠在一起：

| 成分 | 解释方差 | 说明 |
|---|---|---|
| λ₁ × 整体均匀模式 | 70% | 最重要 |
| λ₂ × 左侧偏高模式 | 15% | |
| λ₃ × 中心热点模式 | 8% | |
| λ₄ × 噪声模式 | 0.5% | |
| ... | ... | 后面的成分合计只占 7% |
| λ₁₀₀₀₀ × 纯随机噪声 | ≈0% | 完全可丢 |

前 3 个特征值占了 93% 的方差，后面的加起来只占 7%。砍掉后面 9997 个 → 用 3 个数几乎还原整张图 → **这就是 PCA 降维**。

## SVD — 把任意矩阵拆成三块

### 特征值只能用在方阵上

前面特征值要求 $\mathbf{A}$ 是方阵（$n \times n$）。但现实中大部分数据矩阵不是方的！一张 100×200 的温度图，100 行 200 列，怎么拆？

**SVD 就是特征值分解的通用版——任意形状的矩阵都能用。**

### 公式

$$\mathbf{A} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^\top$$

先别管字母。看这张图：

```
A          =     U          Σ         Vᵀ
(m×n)           (m×m)      (m×n)      (n×n)

[ 数据矩阵 ] = [ 旋转 ] × [ 拉伸 ] × [ 旋转 ]
               "输出     奇异值     "输入
               视角"     从大到小    视角"
                         排列
```

### 这是在干什么

把矩阵 $\mathbf{A}$ 的作用拆成**三步流水线**：

```
输入向量  →  步骤1: Vᵀ 旋转
                调整到数据的"自然方向"上
          →  步骤2: Σ 拉伸/压缩
                每个方向按奇异值缩放
                σ₁方向拉最多（最重要）
                σₙ方向几乎压没（不重要）
          →  步骤3: U 旋转
                转到输出空间的坐标
          →  输出向量
```

**一句话：SVD 告诉你一个矩阵在哪些方向上发力，发力多大。**

### $\mathbf{\Sigma}$ 的对角线才是主角

$$\mathbf{\Sigma} = \begin{bmatrix}
\sigma_1 & 0 & 0 & \cdots & 0 \\
0 & \sigma_2 & 0 & \cdots & 0 \\
0 & 0 & \sigma_3 & \cdots & 0 \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
0 & 0 & 0 & \cdots & \sigma_{\min(m,n)}
\end{bmatrix}$$

$\sigma_1 \geq \sigma_2 \geq \cdots \geq 0$，从大到小排列。

举个温度图的例子（100×100 的图像矩阵做 SVD）：

| $\sigma_i$ | 数值 | 含义 |
|---|---|---|
| $\sigma_1$ | 892 | 最强的结构：整体温度分布趋势 |
| $\sigma_2$ | 231 | 第二强：左右温差模式 |
| $\sigma_3$ | 87 | 第三强：中心-边缘对比 |
| $\sigma_4$ | 12 | 开始变弱：局部纹理 |
| $\sigma_5$ | 3.1 | 很弱：噪声级别的波动 |
| ... | ... | ... |
| $\sigma_{100}$ | 0.02 | 几乎为零：纯噪声 |

$\sigma_{20} / \sigma_1 \approx 0.001$ → 后面 80 个奇异值加起来贡献不到 1%。

**只保留前 20 个，数据几乎无损。**

### 低秩近似

只取前 $k$ 个最大的 $\sigma_i$，其余全部扔掉（当 0）：

$$\mathbf{A}_k = \sum_{i=1}^{k} \sigma_i \mathbf{u}_i \mathbf{v}_i^\top$$

这是数学上可以证明的"用 $k$ 个成分能达到的最佳近似"。

翻译成人话：把数据拆成一堆"成分"的叠加，每个成分 = 奇异值 × 一个输出模式 × 一个输入模式。只保留最重要（奇异值大）的几个成分，扔掉的都是噪声。

## 在深度学习里哪用到了

### PCA

PCA = 对中心化后的数据矩阵做 SVD，取 $\mathbf{V}$ 的前 $k$ 列作为"主成分方向"，把高维数据投影过去。

```
原始数据 X (n×d) → SVD → 取 V 的前k列 → 投影: Z = X V_k (n×k)
                                                      ↑
                                                 从d维降到k维
```

PCA 本质上就是在用 SVD 找"数据的主方向"。

### LoRA（大模型微调的核心技术）

训练大模型时，全量更新权重矩阵 $\mathbf{W}$ 太贵了（GPT 级别的模型参数千亿级）。

LoRA 的思路来自 SVD 低秩近似：权重更新 $\Delta\mathbf{W}$ 虽然理论上是一个大矩阵，但它的**有效秩很低**——不需要存整个矩阵，用两个瘦矩阵乘起来近似就好：

$$\Delta\mathbf{W} \approx \mathbf{B}\mathbf{A}$$

$\mathbf{B} \in \mathbb{R}^{d \times r},\ \mathbf{A} \in \mathbb{R}^{r \times k}$，其中 $r$ 很小（比如 8 或 16）。

这就是 SVD 思想：不是所有维度都重要，低秩近似就够了。参数从 $d \times k$ 降到 $r \times (d + k)$。

### 一个概念串起一条链路

```
SVD → 低秩近似 → PCA 降维 → 异常检测中"正常子空间"建模
              ↘ LoRA → 大模型高效微调
```

## 总结

| 概念 | 画面 | 和前面 1.1.3 的关系 |
|---|---|---|
| 特征值 $\lambda_i$ | 每个方向的"影响力"大小 | 秩 = 非零特征值的个数 |
| 特征向量 $\mathbf{v}_i$ | 数据分布的自然方向 | 选 $k$ 个特征向量 = 基 |
| 奇异值 $\sigma_i$ | 通用版特征值，不限方阵 | $\sigma_i \approx 0$ → 几乎线性相关 |
| SVD 三步 | 旋转 → 拉伸 → 旋转 | 拉伸那步告诉你哪些方向是真重要 |

> **[[1.1.3 线性相关、秩、基与子空间|1.1.3]] 说"秩告诉你独立维度有多少"，1.1.4 说"SVD 告诉你每个独立维度有多重要"。SVD 就是给数据做 CT 扫描——每一层（奇异值）的贡献明明白白。**
