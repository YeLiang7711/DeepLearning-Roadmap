## 直觉

- **标量** $x \in \mathbb{R}$：一个数，比如温度值 $35.2$
- **向量** $\mathbf{x} \in \mathbb{R}^n$：一排数，$\mathbf{x} = [x_1, x_2, \dots, x_n]^\top$，比如三个测温点 $[35.2, 28.1, 42.0]^\top$
- **矩阵** $\mathbf{X} \in \mathbb{R}^{m \times n}$：二维表格，比如 $100 \times 100$ 的温度热图
- **张量** $\mathcal{X} \in \mathbb{R}^{B \times C \times H \times W}$：高维数组，比如 `[批次, 通道, 高度, 宽度]`

## 在深度学习中

```python
# 标量 → 单个损失值
loss = 0.023

# 向量 → 一层的偏置
bias = [0.1, -0.2, 0.3]   # shape: (3,)

# 矩阵 → 一层的权重
weight = [[...], [...], [...]]  # shape: (输入维度, 输出维度)

# 张量 → 一批图像
images = torch.randn(16, 1, 64, 64)  # 16张 单通道 64×64 温度图
```

## 核心公式

**矩阵乘法** — 全连接层的本质：

$$\mathbf{y} = \mathbf{W}\mathbf{x} + \mathbf{b}$$

$$y_i = \sum_{j=1}^{n} W_{ij} \, x_j + b_i$$

即 $\mathbf{W} \in \mathbb{R}^{m \times n},\ \mathbf{x} \in \mathbb{R}^n,\ \mathbf{y} \in \mathbb{R}^m$

**转置**：$(\mathbf{A}^\top)_{ij} = A_{ji}$，行列互换

**Hadamard 积**：$(\mathbf{A} \odot \mathbf{B})_{ij} = A_{ij} \cdot B_{ij}$，逐元素相乘（如 Attention 权重 $\odot$ Value）

> 核心直觉：**矩阵乘法 = 线性变换 = 神经网络全连接层的本质**
