## 线性代数为什么重要

神经网络的核心计算就是**矩阵乘法和求导**。线性代数提供了理解这些操作的"语言"：

- 全连接层 = 矩阵乘法
- Attention = 内积 + Softmax
- PCA 异常检测 = SVD + 投影
- PaDiM = 协方差 + Mahalanobis 距离
- LoRA = 低秩近似

## 快速总结

| 概念 | 一句话 |
|---|---|
| 矩阵乘法 | 线性变换 = 全连接层本质 |
| 内积 | 衡量方向一致性 → Attention |
| L2/欧氏距离 | 直线距离 → PatchCore kNN |
| Mahalanobis 距离 | 考虑分布形状的距离 → PaDiM |
| 秩 | 数据独立维度数 → PCA 降维依据 |
| SVD | 旋转→缩放→旋转分解 → PCA、LoRA |
| 协方差矩阵 | 特征间相关性 → 多元高斯 |
| PCA | 找最重要的方向投影 → 异常检测基线 |
