# 1.2.1 导数、偏导数、方向导数与梯度

> 属于：[[0-概述|微积分]] > 1.2.1
> 掌握程度：**深入** — 梯度是深度学习的引擎

---

## 导数：一个变量的变化率

### 定义

$$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

**直观**：$x$ 变一点点，$f(x)$ 变多少？ $\frac{\Delta f}{\Delta x}$ 在无限小尺度下的极限。

### 和深度学习的关系

损失函数 $\mathcal{L}(w)$ 依赖参数 $w$。$w$ 从 0.5 变成 0.51，损失从 2.3 变成 2.1 → 导数为 $(2.1 - 2.3)/(0.51 - 0.5) = -20$。

导数 $-20$ 告诉我们：$w$ 增大 → 损失快速减小。所以梯度下降往"导数相反的方向"走：

$$w \leftarrow w - \eta \cdot \frac{\partial \mathcal{L}}{\partial w}$$

---

## 偏导数：多元函数沿一个维度的变化率

损失函数从来不止一个参数。$L(w_1, w_2, \dots, w_n)$ 有成千上万个参数。偏导数就是**把其他变量看作常数**，只看一个变量对 $L$ 的影响：

$$\frac{\partial L}{\partial w_1}$$

把 $w_2, w_3, \dots, w_n$ 全当常数，只对 $w_1$ 求导。

**直观**：每个参数都在问"我自己动一下，损失会怎么变？" 偏导数就是给了每个人这个答案。

### 符号约定

| 符号 | 含义 |
|---|---|
| $\frac{df}{dx}$ | 单变量导数 |
| $\frac{\partial f}{\partial x}$ | 多元函数偏导数（其他变量固定） |

---

## 方向导数：沿任意方向的变换率

梯度只告诉你"沿坐标轴走"的变化率。但如果想知道"沿着某个任意方向 $\mathbf{u}$ 走"的变化率，需要方向导数：

$$D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u}$$

**梯度 $\nabla f$ 包含了"沿各个坐标轴"的变化率**，然后和方向向量 $\mathbf{u}$ 做内积，就得到沿 $\mathbf{u}$ 方向的变化率。

> 这里回到 [[../1.1-线性代数/1.1.2 内积、范数、距离与相似度|1.1.2 的内积]]：方向导数 = 梯度向量和方向向量的内积。内积最大当 $\mathbf{u}$ 和 $\nabla f$ 同方向 → 梯度方向就是增长最快的方向。

---

## 梯度：所有偏导数组成的向量

$$\nabla L = \begin{bmatrix} \frac{\partial L}{\partial w_1} & \frac{\partial L}{\partial w_2} & \cdots & \frac{\partial L}{\partial w_n} \end{bmatrix}^\top$$

**梯度的三个关键性质**：

| 性质 | 含义 |
|---|---|
| **梯度指向函数增长最快的方向** | 沿着梯度的反向走 → 损失下降最快 |
| **梯度的大小表示变化有多剧烈** | $\|\nabla L\|$ 大 → 这个位置很陡 |
| **梯度为零 → 局部极值点** | $\nabla L = \mathbf{0}$ → 谷底或鞍点 |

### 梯度下降

$$\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla L(\mathbf{w}_t)$$

```
损失曲面（想象一个碗）

  参数 w₂
    │
    │    ↘   ← 梯度指向最陡的下山方向
    │      ·  ← 当前位置
    │         ↘
    │           · ← 下一步
    └──────────────→ 参数 w₁
```

在 PyTorch 中：
```python
loss.backward()       # 自动计算所有参数的梯度 ∇L
optimizer.step()      # w = w - η·∇L(w)
optimizer.zero_grad() # 清零，准备下一轮
```

---

## 总结

```
导数 f'(x)      → 一个变量对输出的影响
偏导数 ∂f/∂xᵢ   → 多变量下，每个变量各自的影响
梯度 ∇f         → 所有偏导数组成的向量
                 → 指向函数增长最快的方向
                 → 梯度下降 = 沿梯度的反方向更新参数
方向导数        → 梯度 ∇f 和方向 u 做内积
```
