## 激活函数

| 函数 | 表达式 | 导数 | 特点 |
|---|---|---|---|
| **Sigmoid** | $\sigma(x) = \frac{1}{1+e^{-x}}$ | $\sigma(x)(1 - \sigma(x))$ | 处处可导，饱和区梯度≈0 |
| **Tanh** | $\tanh(x) = \frac{e^x-e^{-x}}{e^x+e^{-x}}$ | $1 - \tanh^2(x)$ | 零中心，仍会饱和 |
| **ReLU** | $\max(0, x)$ | $\begin{cases}1 & x>0 \\ 0 & x \leq 0\end{cases}$ | 非饱和，$x=0$ 不可导（实践中用次梯度 0） |
| **Leaky ReLU** | $\max(0.01x, x)$ | $\begin{cases}1 & x>0 \\ 0.01 & x \leq 0\end{cases}$ | 解决 ReLU "神经元死亡" |
| **GELU** | $x \cdot \Phi(x)$ | $\Phi(x) + x \cdot \phi(x)$ | Transformer 标配，处处可导 |
| **SiLU / Swish** | $x \cdot \sigma(x)$ | $\sigma(x) + x \cdot \sigma(x)(1-\sigma(x))$ | 自门控，平滑非单调 |

其中 $\Phi(x)$ 是标准正态 CDF，$\phi(x)$ 是标准正态 PDF。

## 损失函数（对预测值 $\hat{y}$ 的导数）

| 函数 | 表达式 | $\frac{\partial L}{\partial \hat{y}}$ | 场景 |
|---|---|---|---|
| **MSE** | $\frac{1}{2}(\hat{y} - y)^2$ | $\hat{y} - y$ | 回归 |
| **MAE** | $|\hat{y} - y|$ | $\text{sign}(\hat{y} - y)$ | 回归（抗异常值） |
| **Huber** | 分段：小误差用 MSE，大误差用 MAE | 分段导数 | 回归（兼顾两者） |
| **BCE** | $-[y\log\hat{y} + (1-y)\log(1-\hat{y})]$ | $\frac{\hat{y}-y}{\hat{y}(1-\hat{y})}$ | 二分类（需和 Sigmoid 联用） |
| **CE (多分类)** | $-\sum_k y_k \log \hat{y}_k$ | — | 多分类（和 Softmax 联用） |

### Softmax + 交叉熵的联合导数（最常用的组合）

单独对 Softmax 求导很复杂（Jacobian 是 $n \times n$）。但 **Softmax + 交叉熵** 联合求导简洁得惊人：

$$z^{(l)} = \text{softmax}(x^{(l)}) = \frac{e^{x_l}}{\sum_j e^{x_j}}$$

$$L = -\sum_l y_l \log z^{(l)}$$

$$\frac{\partial L}{\partial x^{(l)}} = z^{(l)} - y^{(l)}$$

**Softmax 输出减去 One-hot 标签。** 这是分类任务反向传播最常用的公式——记这一个就够了。

## 常用运算

| 运算 | 导数 |
|---|---|
| $f(x) = cx$ | $f'(x) = c$ |
| $f(x) = x^n$ | $f'(x) = n x^{n-1}$ |
| $f(x) = e^x$ | $f'(x) = e^x$ |
| $f(x) = \ln x$ | $f'(x) = \frac{1}{x}$ |
| $f(x) = \log_a x$ | $f'(x) = \frac{1}{x \ln a}$ |
| $f(x) = \sin x$ | $f'(x) = \cos x$ |
| $f(x) = \cos x$ | $f'(x) = -\sin x$ |

### 运算法则

| 法则 | 公式 |
|---|---|
| 加法法则 | $(f+g)' = f' + g'$ |
| 乘法法则 | $(fg)' = f'g + fg'$ |
| 除法法则 | $\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$ |
| 链式法则 | $(f \circ g)'(x) = f'(g(x)) \cdot g'(x)$ |

## 梯度 = 0 的含义

PyTorch 中如果一个参数梯度为 0，原因通常是：

| 原因 | 诊断方式 |
|---|---|
| ReLU 神经元死亡（总是输出 0） | 检查激活值是否大量为 0 |
| 学习率过大，跳过最优解 | 检查损失是否震荡 |
| 数据提供的信息已用尽（收敛） | 损失不再下降 → 训练完成 |
| 计算图断裂（`detach()` 或 `with torch.no_grad()`） | 梯度流被手动切断 |
| 初始化为 0 或对称 | 每个神经元学到的完全一样 |
