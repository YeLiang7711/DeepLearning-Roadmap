## 链式法则

### 复合函数求导

$$y = f(g(x)) \quad \Rightarrow \quad \frac{dy}{dx} = \frac{dy}{dg} \cdot \frac{dg}{dx}$$

三层复合：

$$y = f(g(h(x))) \quad \Rightarrow \quad \frac{dy}{dx} = \frac{dy}{dg} \cdot \frac{dg}{dh} \cdot \frac{dh}{dx}$$

**直观**：想知道输入的变化最终怎么影响输出，就把每一层的"传导效果"乘起来。

### 多元链式法则

深度学习里函数依赖关系是图状的（一个参数影响多个中间变量），所以用偏导数：

$$\frac{\partial L}{\partial w} = \sum_i \frac{\partial L}{\partial z_i} \cdot \frac{\partial z_i}{\partial w}$$

$L$ 通过 $z_1, z_2, \dots$ 等多条路径依赖 $w$，每条路径的贡献都要加总。

## 反向传播：用链式法则高效算梯度

### 神经网络前向传播的计算图

一个最简单的两层网络：

```
输入 x ──→ [W₁] ──→ z₁ ──→ [ReLU] ──→ a₁ ──→ [W₂] ──→ z₂ ──→ loss(y, ŷ)
                     ↑                        ↑
                    参数 W₁                   参数 W₂
```

用数学写：

$$\begin{aligned}
z_1 &= W_1 x + b_1 \\
a_1 &= \text{ReLU}(z_1) = \max(0, z_1) \\
z_2 &= W_2 a_1 + b_2 \\
L &= \text{MSE}(z_2, y) = \frac{1}{2}(z_2 - y)^2
\end{aligned}$$

我们想知道：$\frac{\partial L}{\partial W_1}$ 和 $\frac{\partial L}{\partial W_2}$。$L$ 不直接依赖 $W_1$，要通过 $z_2 \to a_1 \to z_1$ 一路穿回去。

### 从后往前链式传导

**第一步**：损失对输出 $z_2$ 的梯度

$$\frac{\partial L}{\partial z_2} = z_2 - y$$

**第二步**：通过 $z_2 \to W_2$ 拿 $W_2$ 的梯度

$$\frac{\partial L}{\partial W_2} = \frac{\partial L}{\partial z_2} \cdot \frac{\partial z_2}{\partial W_2} = (z_2 - y) \cdot a_1$$

**第三步**：求 $\frac{\partial L}{\partial a_1}$，为继续往前面传做准备

$$\frac{\partial L}{\partial a_1} = \frac{\partial L}{\partial z_2} \cdot \frac{\partial z_2}{\partial a_1} = (z_2 - y) \cdot W_2$$

**第四步**：通过 ReLU

$$\frac{\partial L}{\partial z_1} = \frac{\partial L}{\partial a_1} \cdot \frac{\partial a_1}{\partial z_1} = \frac{\partial L}{\partial a_1} \cdot \mathbb{1}[z_1 > 0]$$

ReLU 的导数：$z_1 > 0$ 时导数为 1（信号过），$z_1 \leq 0$ 时导数为 0（信号截断）。

**第五步**：拿到 $W_1$ 的梯度

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial z_1} \cdot \frac{\partial z_1}{\partial W_1} = \frac{\partial L}{\partial z_1} \cdot x$$

### 为什么叫"反向"传播

```
前向传播（计算输出）：x → z₁ → a₁ → z₂ → L
                        → → → → →
反向传播（计算梯度）：x ← z₁ ← a₁ ← z₂ ← L
                        ← ← ← ← ←
                       每一步都在用链式法则
```

### PyTorch 自动做的事

```python
# 前向
x = torch.tensor([1.0, 2.0])
z1 = W1 @ x + b1
a1 = torch.relu(z1)
z2 = W2 @ a1 + b2
loss = ((z2 - y) ** 2).mean()

# 反向 — 自动计算 ∂L/∂W1, ∂L/∂W2, ∂L/∂b1, ∂L/∂b2
loss.backward()

print(W1.grad)  # ∂L/∂W1，自动算好了
```

`.backward()` 的本质就是一个巨大的链式法则引擎——沿着计算图从损失往回走，每到一个节点就乘上"当地导数"，一直传到每个叶子参数。

## 为什么链式法则是 DL 的数学根基

```
损失函数 L(θ) 依赖数百万参数 θ

↓ 如果每个参数单独求偏导，要前向传播数百万次（不可行）

链式法则：对计算图做一遍前向 + 一遍反向
          → 一次性算出所有参数的所有梯度
          → 时间复杂度 = 前向传播的常数倍

这就是为什么深度学习可以训练百万、亿级参数的模型。
```

## 总结

| 概念 | 做啥 |
|---|---|
| 链式法则 | 复合函数求导：$\frac{dy}{dx} = \frac{dy}{dz} \cdot \frac{dz}{dx}$ |
| 计算图 | 神经网络的计算分解为节点和边 |
| 前向传播 | 输入 → 输出，算损失 |
| 反向传播 | 损失 → 输入，通过链式法则一次性算所有梯度 |
| `.backward()` | PyTorch 的自动链式法则引擎 |
