## 微积分在深度学习中用在哪儿

深度学习的核心算法是**梯度下降**——沿着使损失函数下降最快的方向调整参数。而梯度本身就是微积分定义的：

- **导数** → 单变量函数的变化率 → 一个参数对损失的影响
- **偏导数** → 多元函数沿一个方向的变化率 → 每个参数各自的梯度分量
- **梯度** → 所有偏导数组成的向量 → 参数更新的方向和步长
- **链式法则** → 复合函数求导 → 反向传播的数学基础
- **Jacobian / Hessian** → 高级优化、网络分析
