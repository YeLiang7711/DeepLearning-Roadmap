# 1.3.5 置信区间、分位数、假设检验

> 属于：[[0-概述|概率统计]] > 1.3.5
> 掌握程度：**会用** — 这是异常阈值设定和模型比较的统计依据

---

## 置信区间

### 定义

对参数 $\theta$ 的一个区间估计，使得该区间以指定概率（置信水平，通常 95%）覆盖真值：

$$P(\hat{\theta}_L \leq \theta \leq \hat{\theta}_U) = 1 - \alpha$$

$\alpha = 0.05$ → 95% 置信区间。

**直观**：如果重复实验 100 次，每次算一个 95% 置信区间，大约 95 个区间会包含真实的参数值。不是"$\theta$ 落在该区间的概率是 95%"（$\theta$ 不是随机变量，区间才是随机的）。

### 在 DL 中

- 交叉验证结果汇报：准确率 $0.873 \pm 0.012$（95% CI）
- **报告模型性能不报置信区间 = 不可信**。用不同随机种子跑 5-10 次，算均值 ± 标准差。

## 分位数

### 定义

$q_\alpha$ 是使得有 $\alpha$ 比例的数据落在它之下的值：

$$P(X \leq q_\alpha) = \alpha$$

| 名称 | $\alpha$ | DL 中用途 |
|---|---|---|
| 中位数（Median） | 0.50 | 稳健的中心趋势 |
| 下四分位数 Q1 | 0.25 | 箱线图 |
| 上四分位数 Q3 | 0.75 | 箱线图 |
| 95% 分位数 | 0.95 | 异常检测阈值 |
| 99% 分位数 | 0.99 | 严格异常阈值 |

### 用分位数设定异常阈值

不需要假设分布。直接算正常训练集的分数分布，取第 95（或 99）百分位作为阈值：

```
正常样本异常分数 → 从小到大排序 → 取 95% 分位值 → 超过这个值 = 异常
```

这比 $3\sigma$ 规则更灵活，不依赖高斯假设。

## 假设检验

### 基本框架

| 假设 | 含义 |
|---|---|
| $H_0$（零假设/原假设） | 默认立场："没效果" / "正常" |
| $H_1$（备择假设） | 对立立场："有效果" / "异常" |
| $\alpha$（显著性水平） | 允许犯第一类错误的概率上限（通常 0.05） |
| $p$ 值 | 在原假设为真的前提下，观测到当前数据或更极端数据的概率 |

### 两类错误

| | 实际 $H_0$ 为真 | 实际 $H_1$ 为真 |
|---|---|---|
| **判定接受 $H_0$** | ✅ 正确 | ❌ 第二类错误（漏报） |
| **判定拒绝 $H_0$** | ❌ 第一类错误（误报） | ✅ 正确 |

### 在异常检测中的映射

| 统计概念 | 异常检测对应 |
|---|---|
| $H_0$ | 样本正常 |
| $H_1$ | 样本异常 |
| $\alpha$（第一类错误率） | 误报率 FPR |
| 第二类错误率 $\beta$ | 漏报率 FNR |
| $p$ 值 | 异常分数的"极端程度" |

AUROC 就是对所有可能的阈值，遍历"第一类 vs 第二类错误"的权衡曲线。

---

## 总结

| 工具 | 用途 |
|---|---|
| 置信区间 | 报告指标时给出不确定性范围 |
| 分位数 | 不依赖分布的异常阈值设定 |
| $p$ 值 | 量化"正常情况看到这个数据的概率" |
| 假设检验 | 异常检测的统计框架：$H_0$=正常 vs $H_1$=异常 |
