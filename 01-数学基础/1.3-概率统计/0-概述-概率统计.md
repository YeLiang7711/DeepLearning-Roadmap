## 概率统计在深度学习中用在哪儿

深度学习处理的是**不确定性**：数据有噪声、模型有随机性、预测是概率分布而非确定值。

- **期望/方差** → BatchNorm 的统计量、损失函数的期望风险
- **条件概率/贝叶斯** → 生成模型（VAE/Diffusion）、贝叶斯深度学习
- **高斯分布** → VAE 的潜变量先验、PaDiM 的位置高斯建模
- **最大似然估计** → 交叉熵损失 = 最大似然，MSE = 高斯假设下的最大似然
- **置信区间/假设检验** → 模型评估的显著性、异常阈值确定
- **稳健统计** → 小样本下抗异常值，Median/MAD 比均值/标准差更稳
- **偏差—方差权衡** → 过拟合/欠拟合的理论框架
