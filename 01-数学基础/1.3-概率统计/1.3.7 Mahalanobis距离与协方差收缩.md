## Mahalanobis 距离：回顾与深化

[[../../01-数学基础/1.1-线性代数/1.1.2 内积、范数、距离与相似度|1.1.2]] 已给出公式和几何直觉，这里从概率统计角度深化。

### 从多元高斯出发

多元高斯的概率密度：

$$f(\mathbf{x}) \propto \exp\!\left(-\frac{1}{2} (\mathbf{x} - \boldsymbol{\mu})^\top \mathbf{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})\right)$$

指数内的二次型就是 Mahalanobis 距离的平方。

等高线（等概率密度线）是 Mahalanobis 距离相等的点组成的椭圆。**Mahalanobis 距离越大 → 概率密度越低 → 点越不可能来自该分布。**

### 异常检测中的应用

为正常数据拟合多元高斯，对新样本计算 Mahalanobis 距离 → 超过阈值 → 异常。

$$s = \sqrt{(\mathbf{x} - \boldsymbol{\mu})^\top \mathbf{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})}$$

$s$ 是标量。设定阈值（如基于正常验证集的分位数）即可做判定。

## 协方差矩阵的实用问题

### 更深入：样本协方差的统计特性

用 $n$ 个样本估计 $d$ 维协方差矩阵。如果 $d > n$，样本协方差矩阵天然奇异，不借助正则化完全无法求逆。

**即使 $d < n$ 但 $d/n$ 不太小**（比如 $d=500, n=1000$），样本协方差在统计上也远不如低维情形可靠——特征值被系统性地分散，大的偏大、小的偏小。

### Shrinkage（收缩估计）

在样本协方差和结构化目标（如单位矩阵）之间做凸组合：

$$\hat{\mathbf{\Sigma}}_{\text{shrink}} = (1 - \alpha) \mathbf{\Sigma}_{\text{sample}} + \alpha \mathbf{T}$$

- $\mathbf{T}$ 是 Target 矩阵（通常选 $\mathbf{I}$ 或 $\text{diag}(\mathbf{\Sigma}_{\text{sample}})$）
- $\alpha \in [0, 1]$ 是收缩强度

等价于加正则：$\hat{\mathbf{\Sigma}}^{-1} \approx (\mathbf{\Sigma}_{\text{sample}} + \lambda \mathbf{I})^{-1}$

**直觉**：样本协方差对真实协方差的估计有误差，往对角线加一点"自己"把它往单位矩阵方向拉，稳定了求逆的结果。

### Ledoit-Wolf 收缩

自动选择最优 $\alpha$ 的方法（最小化 MSE 意义下）。scikit-learn 中 `LedoitWolf` 可直接调用。

### 在 PaDiM 中的实际处理

PaDiM 为特征图每个 $(h,w)$ 位置估计一个协方差矩阵。对于正常样本数 $n$ 和特征维度 $d$：

- 如果 $n \gg d$：直接用样本协方差求逆
- 如果 $n$ 和 $d$ 接近或 $n < d$：必须用 shrinkage

```python
from sklearn.covariance import LedoitWolf
lw = LedoitWolf().fit(features_hw)
prec = lw.precision_  # 收缩后的 Σ^{-1}
```

## 总结

| 概念 | 要点 |
|---|---|
| Mahalanobis 距离 | 多元高斯概率密度的核心度量 |
| $d > n$ 问题 | 样本协方差天然奇异 |
| Shrinkage | $\Sigma + \lambda I$，把奇异矩阵"救回来" |
| Ledoit-Wolf | 自动选最优收缩强度 |
