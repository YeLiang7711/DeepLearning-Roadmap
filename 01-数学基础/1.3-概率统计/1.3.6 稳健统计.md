# 1.3.6 稳健统计

> 属于：[[0-概述|概率统计]] > 1.3.6
> 掌握程度：**会用** — 小样本和高噪声场景下比经典统计可靠

---

## 为什么需要稳健统计

**经典统计的脆弱性**：均值被 1 个异常值就能拉偏；标准差被异常值放大。如果你的正常数据只有 100 张图且可能有暗藏的污染样本，均值 ± 标准差建立的基线可能从基础上就错了。

**稳健统计的目标**：对离群值和模型假设的偏离不敏感。

---

## 经典 vs 稳健

### 中心趋势：均值 vs 中位数

```
数据：[25, 26, 25, 24, 25, 25, 25, 200]
                                 ↑ 一个异常值

均值 = 46.9    ← 被 200 严重拉偏，完全不能代表"正常"
中位数 = 25    ← 不受影响，稳健
```

### 离散度：标准差 vs MAD

**MAD（Median Absolute Deviation）**：

$$\text{MAD} = \text{median}(|x_i - \text{median}(x_j)|)$$

```
数据分布是 25±1，但混入一个 200：
  标准差：被 200 拉到极大
  MAD：    ≈ 1.48 × 正常的 75% 分位，对 200 几乎无视
```

MAD 用中位数替代均值，不平方（平方会放大离群值），异常值的影响几乎为零。

### 判断离群值：$z$-score vs 稳健 $z$-score

**经典 $z$-score**：$z = \frac{x - \bar{x}}{s}$（均值和标准差都被异常值污染）

**稳健 $z$-score**：$z_{\text{robust}} = \frac{x - \text{median}}{\text{MAD} / 0.6745}$

除以 0.6745 是为了让 MAD 在高斯分布下和标准差的尺度对齐（$\text{MAD} \approx 0.6745\sigma$ 对于 $\mathcal{N}(0,1)$）。

**异常检测中**：正常样本少时，优先用 Median/MAD 做基线，而不是均值/标准差。100 张图里混了一张污染，均值就歪了，中位数纹丝不动。

---

## Huber 损失

### 修复 MSE 对异常值的过度敏感

MSE 对远离均值的点惩罚以距离的平方增长 → 异常值主导梯度。MAE 对所有距离线性惩罚 → 对正常数据的微小误差响应不够精细。

Huber 损失在两者间平滑过渡：

$$L_\delta(r) = \begin{cases}
\frac{1}{2}r^2 & \text{for } |r| \leq \delta \\[4pt]
\delta \cdot (|r| - \frac{1}{2}\delta) & \text{for } |r| > \delta
\end{cases}$$

```
        损失
         │        ╱
         │      ╱  ← |r| > δ: 线性增长（像 MAE，抗异常值）
         │   ╱
         │ ╱  ← |r| ≤ δ: 二次增长（像 MSE，对小误差精细）
         └──────────→ 残差 r
```

$\delta$ 控制切换点。$\delta$ 小 → 更像 MAE；$\delta$ 大 → 更像 MSE。通常 $\delta = 1.345$（在 $\mathcal{N}(0,1)$ 下达到 95% 效率）。

---

## Breakdown Point

**定义**：使估计值偏离真值任意远所需的最小污染比例。

| 估计量 | Breakdown Point |
|---|---|
| 均值 | $1/n$（1 个异常就歪） |
| 中位数 | 50%（要污染过半才歪） |
| MAD | 50% |
| Huber（固定 $\delta$） | $1/n$（虽比 MSE 好，但 $\delta$ 固定时仍可被大量异常攻破） |

> 极端离群值多的时候，中位数和 MAD 是比均值和标准差更安全的选择。

---

## 总结

| | 经典 | 稳健 |
|---|---|---|
| 中心趋势 | 均值 | 中位数 |
| 离散度 | 标准差 | MAD |
| 标准化 | $z$-score | 稳健 $z$-score |
| 回归损失 | MSE | Huber / MAE |
| 对 1 个异常值 | 敏感 | 无视 |
| 对 50% 污染 | 崩溃 | 中位数仍有效 |

> 在异常检测中建立基线时，优先用 Median/MAD，这是一种用很少的额外成本换来的显著稳健性提升。
