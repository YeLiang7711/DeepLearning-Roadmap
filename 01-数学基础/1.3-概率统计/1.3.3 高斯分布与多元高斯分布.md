# 1.3.3 高斯分布与多元高斯分布

> 属于：[[0-概述|概率统计]] > 1.3.3
> 掌握程度：**深入** — 高斯分布是深度学习中最重要的概率分布

---

## 为什么高斯分布无处不在

**中心极限定理**：大量独立同分布随机变量的均值，近似服从高斯分布。

这意味着：测量误差、传感器噪声、批次间波动……大量自然现象的数据分布都接近高斯。深度学习中的很多假设（MSE 损失 ≈ 输出服从高斯；VAE 先验 = 标准高斯）的根源都在这里。

---

## 一元高斯分布

### 概率密度函数

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

两个参数控制一切：
- $\mu$：均值，钟形曲线的中心位置
- $\sigma^2$：方差，钟形曲线有多"胖"（$\sigma$ 越大越分散）

### 标准化

$$z = \frac{x - \mu}{\sigma}$$

$z$ 服从标准正态 $\mathcal{N}(0, 1)$。这就是数据预处理中常用的 **Z-score 标准化**。

### 68-95-99.7 规则

```
        ┌─────────┐
        │  68.3%  │  ← μ ± σ
     ┌──┴─────────┴──┐
     │     95.4%     │  ← μ ± 2σ
  ┌──┴───────────────┴──┐
  │       99.7%         │  ← μ ± 3σ
──┴─────────────────────┴──
```

$\mu \pm 3\sigma$ 包含了 99.7% 的数据。异常检测中的 $3\sigma$ 阈值来自这里：超出这个范围 → 概率极低 → 很可能是异常。

---

## 多元高斯分布

### 从一元到多元

一元：一个特征，分布由 $\mu$ 和 $\sigma^2$ 决定。

多元：$d$ 个特征，分布由均值向量 $\boldsymbol{\mu} \in \mathbb{R}^d$ 和协方差矩阵 $\mathbf{\Sigma} \in \mathbb{R}^{d \times d}$ 决定。

### 概率密度函数

$$f(\mathbf{x}) = \frac{1}{(2\pi)^{d/2} |\mathbf{\Sigma}|^{1/2}} \exp\!\left(-\frac{1}{2} (\mathbf{x} - \boldsymbol{\mu})^\top \mathbf{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})\right)$$

核心是中间那个二次型：$(\mathbf{x} - \boldsymbol{\mu})^\top \mathbf{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})$

这就是 Mahalanobis 距离的平方。指数里 Mahalanobis 距离越大 → 概率密度越低 → 这个点越不可能来自该分布。

### $\mathbf{\Sigma}$ 如何控制分布形状

| $\mathbf{\Sigma}$ | 分布形状 | 含义 |
|---|---|---|
| 各向同性 $\sigma^2 \mathbf{I}$ | 正圆形等高线 | 各维度独立且同方差 |
| 对角阵（非对角为 0） | 轴对齐的椭圆 | 各维度独立但方差不同 |
| 非对角非零 | 倾斜的椭圆 | 维度之间有相关性 |

### 在 DL 中

**VAE**：编码器输出 $(\mu, \log\sigma^2)$，解码器从 $\mathcal{N}(\mu, \sigma^2)$ 采样潜变量 $z$。重参数化技巧：$z = \mu + \sigma \odot \epsilon,\ \epsilon \sim \mathcal{N}(0, I)$，让采样过程可导。

**PaDiM**：为特征图每个位置 $(h,w)$ 拟合一个多元高斯 $\mathcal{N}(\boldsymbol{\mu}_{h,w}, \mathbf{\Sigma}_{h,w})$。每个位置有自己的协方差 → 高波动区容忍度大，稳定区很严格。

**Diffusion 模型**：前向过程逐步加高斯噪声 $q(x_t \mid x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t}x_{t-1}, \beta_t I)$。反向过程学习去噪，也是高斯分布。

---

## 总结

| 分布 | 参数 | DL 中 |
|---|---|---|
| 一元高斯 | $\mu, \sigma^2$ | Z-score 标准化、$3\sigma$ 阈值 |
| 多元高斯 | $\boldsymbol{\mu}, \mathbf{\Sigma}$ | VAE 潜变量、PaDiM 位置建模 |
| 标准高斯 $\mathcal{N}(0,I)$ | 固定 | VAE 先验、Diffusion 噪声、参数初始化 |
