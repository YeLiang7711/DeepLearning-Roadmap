# 1.3.4 最大似然估计与最大后验估计

> 属于：[[0-概述|概率统计]] > 1.3.4
> 掌握程度：**会用** — 理解交叉熵和 L2 正则从哪来

---

## 问题设定

你有观测数据 $\mathcal{D} = \{x_1, x_2, \dots, x_n\}$，假设数据来自某个参数化的分布 $P(x \mid \theta)$。**如何从数据反推参数 $\theta$？**

---

## 最大似然估计（MLE）

### 核心思想

> 选那个使"观测到现有数据"的概率最大的 $\theta$

### 似然函数

$$L(\theta) = P(\mathcal{D} \mid \theta) = \prod_{i=1}^n P(x_i \mid \theta)$$

各样本独立 → 联合概率 = 各样本概率的乘积。

由于乘积容易数值下溢且求导麻烦，取对数：

$$\ell(\theta) = \log L(\theta) = \sum_{i=1}^n \log P(x_i \mid \theta)$$

$$\theta_{\text{MLE}} = \arg\max_\theta \ell(\theta)$$

### 深度学习里的 MLE

假设输出服从高斯分布（回归）或分类分布（分类），最小化损失函数 = 最大化对数似然：

| 任务 | 分布假设 | 负对数似然 | 对应损失 |
|---|---|---|---|
| 回归 | $y \sim \mathcal{N}(f_\theta(x), \sigma^2)$ | $\frac{1}{2\sigma^2}(y - f_\theta(x))^2 + \text{const}$ | **MSE** |
| 二分类 | $y \sim \text{Bernoulli}(f_\theta(x))$ | $-y\log\hat{y} - (1-y)\log(1-\hat{y})$ | **BCE** |
| 多分类 | $y \sim \text{Categorical}(f_\theta(x))$ | $-\sum_k y_k \log \hat{y}_k$ | **交叉熵** |

> MSE、BCE、交叉熵不是随便选的——它们是对应分布假设下最大似然估计的自然结果。

---

## 最大后验估计（MAP）

### MLE 的问题

MLE 只看数据拟合得好不好，样本少时容易过拟合。

**MAP 把关于参数的经验知识（先验）加进来。**

### 贝叶斯框架

$$P(\theta \mid \mathcal{D}) \propto P(\mathcal{D} \mid \theta) \cdot P(\theta)$$

后验 ∝ 似然 × 先验

$$\theta_{\text{MAP}} = \arg\max_\theta \left[\log P(\mathcal{D} \mid \theta) + \log P(\theta)\right]$$

### MAP = MLE + 正则化

**高斯先验** $P(\theta) \sim \mathcal{N}(0, \sigma_0^2)$ 下：

$$\log P(\theta) \propto -\frac{\|\theta\|^2}{2\sigma_0^2}$$

代入 MAP：

$$\theta_{\text{MAP}} = \arg\max_\theta \left[\sum_i \log P(x_i \mid \theta) - \lambda \|\theta\|_2^2\right]$$

其中 $\lambda = 1/(2\sigma_0^2)$。**这就是 L2 正则化（权重衰减）。**

| 先验 | $\log P(\theta)$ | 对应正则化 |
|---|---|---|
| 高斯 $\mathcal{N}(0, \sigma^2)$ | $-\frac{1}{2\sigma^2}\|\theta\|^2$ | **L2 正则化** |
| 拉普拉斯 | $-\lambda \|\theta\|_1$ | **L1 正则化**（稀疏） |

> **L2 正则化不是"工程技巧"，而是"假设参数服从高斯先验"下的 MAP 估计。**

---

## MLE vs MAP 对比

| | MLE | MAP |
|---|---|---|
| 框架 | 频率学派 | 贝叶斯学派 |
| 参数 | 固定但未知 | 随机变量，有先验分布 |
| 优化 | $\max \sum \log P(x_i \mid \theta)$ | $\max \left[\sum \log P(x_i \mid \theta) + \log P(\theta)\right]$ |
| 等价 | 无正则化的损失最小化 | 带正则化的损失最小化 |
| 问题 | 小样本过拟合 | 先验选得不好引入偏差 |

---

## 总结

```
MLE  → 最大化似然      → MSE / 交叉熵损失
MAP  → MLE + 先验      → MSE / 交叉熵 + L1/L2 正则化
贝叶斯 → 求完整后验分布  → VAE、贝叶斯神经网络
```
