**本节内容**：MLE 是"数据说了算"、MAP 是"数据+先验"：MSE=高斯似然、L2=高斯先验。

> 属于：[[0-概述-概率统计|概率统计]] > 1.3.4
> 掌握程度：**会用** — 理解"MSE 从哪来"和"L2 正则为什么有效"的深层原因

---

## 一个问题，两种做法

你有一个温度传感器，测了 5 次同一个位置：

```
测量值：24.8, 25.3, 24.9, 25.1, 24.9
```

传感器有随机噪声，每次测量不完全相同。**这 5 个数背后，真实温度最可能是多少？**

直觉答案：取平均，25.0。但为什么取平均？取中位数行不行？取 24.9 行不行？

MLE 和 MAP 就是两种**系统化回答这类问题的方法**。

---

## 最大似然估计

MLE：只看数据，不管别的。

### 核心思路

**反推**：假设真实温度是 θ，那观测到"24.8, 25.3, 24.9, 25.1, 24.9"这组数据的概率有多大？选让这个概率最大的 θ。

### 把例子变成数学

假设每次测量的误差服从高斯分布 $\mathcal{N}(0, \sigma^2)$（传感器噪声是高斯噪声——这个假设很常见，[[1.3.3 高斯分布与多元高斯分布|1.3.3]] 讲过中心极限定理）。

如果真实温度是 θ，那么测量值 $x_i$ 出现的概率密度是：

$$P(x_i \mid \theta) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(x_i - \theta)^2}{2\sigma^2}\right)$$

5 次测量独立，联合概率 = 各自概率的乘积：

$$L(\theta) = P(x_1, \dots, x_5 \mid \theta) = \prod_{i=1}^5 \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(x_i - \theta)^2}{2\sigma^2}\right)$$

L(θ) 就是**似然函数**——"参数 θ 能产生这组数据的概率（密度）"。

MLE 要找让 L(θ) 最大的 θ。

### 乘积不好算，取对数

连乘 → 取 log 变连加（不改变最大值的位置）：

$$\log L(\theta) = \sum_{i=1}^5 \left[ -\frac{1}{2}\log(2\pi\sigma^2) - \frac{(x_i - \theta)^2}{2\sigma^2} \right]$$

和 θ 有关的只有 $-(x_i - \theta)^2$ 那一项，而且前面有负号。要让 log L(θ) 最大 → 让 $\sum (x_i - \theta)^2$ 最小。

**求导，令等于 0**：

$$\frac{d}{d\theta}\sum (x_i - \theta)^2 = -2\sum (x_i - \theta) = 0 \quad\Rightarrow\quad \theta = \frac{1}{5}\sum_{i=1}^5 x_i = 25.0$$

**MLE 告诉你：如果假设噪声是高斯分布，那么"最可能"的真实温度就是测量值的算术平均。** 不是感觉，不是经验，是推导出来的。

### MLE 的一般形式

$$\theta_{\text{MLE}} = \arg\max_\theta \sum_{i=1}^n \log P(x_i \mid \theta)$$

**选 θ，使得观测到已有数据的对数概率最大。**

### 拿到深度学习里

不同任务的"噪声假设"不同，MLE 对应不同的损失函数：

| 任务 | 假设模型输出服从什么分布 | MLE 等价于最小化 |
|---|---|---|
| 回归（预测连续值） | 高斯分布：$y \sim \mathcal{N}(f_\theta(x), \sigma^2)$ | **MSE** = $\frac{1}{n}\sum(y_i - f_\theta(x_i))^2$ |
| 回归（抗异常值） | 拉普拉斯分布：$y \sim \text{Laplace}(f_\theta(x), b)$ | **MAE** = $\frac{1}{n}\sum\|y_i - f_\theta(x_i)\|$ |
| 二分类 | 伯努利分布：$y \sim \text{Bernoulli}(p)$ | **BCE** = $-\frac{1}{n}\sum[y_i\log p_i + (1-y_i)\log(1-p_i)]$ |
| 多分类 | 类别分布：$y \sim \text{Categorical}(\mathbf{p})$ | **交叉熵** = $-\frac{1}{n}\sum_k y_{ik}\log p_{ik}$ |

> MSE、BCE、交叉熵不是工程上"试试哪个好用"——它们是在各自分布假设下，MLE 推导出来的**唯一正确选择**。

### 补充：MAE 的拉普拉斯假设

[[1.3.6 稳健统计|1.3.6]] 讲过 MAE 比 MSE 抗异常值，它的统计来源是**拉普拉斯分布**：

$$P(\varepsilon) = \frac{1}{2b}\exp\!\left(-\frac{|\varepsilon|}{b}\right)$$

代入最大似然 $\max_\theta \sum_i \log P(y_i - f_\theta(x_i))$，去掉常数项后等价于：

$$\min_\theta \sum_i |y_i - f_\theta(x_i)| = \min \text{MAE}$$

**关键区别在于两个分布的尾巴**：

| 噪声假设 | 分布形状 | 对大误差的态度 | 得到损失 |
|---|---|---|---|
| 高斯分布 | 尾巴很薄，大误差概率极低 | 出现大误差 → 重罚（平方） | **MSE** |
| 拉普拉斯分布 | 尾巴较厚，大误差不那么罕见 | 大误差 → 线性惩罚（宽容） | **MAE** |

> 一个分布假设就决定了损失函数的样子。**想让模型抗异常值，不是换损失函数，而是换"误差分布假设"。**

## MLE 有什么问题

回到温度传感器。假设你只测了 **2 次**：24.8 和 25.2。MLE = 25.0。

但假设你测了 2 次全是异常值：15.0 和 16.0（传感器故障）。MLE = 15.5——它完全被数据带偏了，没有抵抗异常值的能力。

更根本的问题：**如果数据很少，MLE 完全信任数据，没有任何"常识"兜底。**

---

## 最大后验估计

MAP：数据说了算，但我也有个预判。

### 加入先验知识

在测量之前，你知道这个位置的温度**大概在 25°C 左右**（比如来自物理模型或历史数据）。你对"θ 应该是多少"已经有一个先验信念。

测量两次得到了 15 和 16。MLE 说 θ=15.5。但你的先验说"θ 大概 25"——**MAP 在两者之间折中**。

### 数学表达

回顾贝叶斯公式（[[1.3.2 条件概率与贝叶斯公式|1.3.2]]）：

$$P(\theta \mid \text{数据}) \propto P(\text{数据} \mid \theta) \cdot P(\theta)$$

- $P(\theta)$ = 先验：还没测量时，你对 θ 的初始判断。比如"θ 大概服从均值为 25、方差为 1 的高斯分布"
- $P(\text{数据} \mid \theta)$ = 似然：和 MLE 一样，数据有多支持这个 θ
- $P(\theta \mid \text{数据})$ = 后验：看到数据后，更新过的对 θ 的判断

MAP 就是找让后验最大的 θ：

$$\theta_{\text{MAP}} = \arg\max_\theta \left[ \log P(\text{数据} \mid \theta) + \log P(\theta) \right]$$

$$\theta_{\text{MAP}} = \arg\max_\theta \left[ \underbrace{\sum_{i=1}^n \log P(x_i \mid \theta)}_{\text{和数据有关（MLE 也有）}} + \underbrace{\log P(\theta)}_{\text{先验，MLE 没有}} \right]$$

### 高斯先验 → L2 正则化

假设先验是 $\theta \sim \mathcal{N}(0, \sigma_0^2)$（参数应该比较小，集中在 0 附近）：

$$\log P(\theta) = -\frac{\theta^2}{2\sigma_0^2} + \text{常数} \propto -\frac{1}{2\sigma_0^2} \|\theta\|^2$$

代入 MAP：

$$\theta_{\text{MAP}} = \arg\max_\theta \left[ \sum_{i=1}^n \log P(x_i \mid \theta) - \frac{1}{2\sigma_0^2} \|\theta\|^2 \right]$$

再令 $\lambda = \frac{1}{2\sigma_0^2}$：

$$\theta_{\text{MAP}} = \arg\max_\theta \left[ \sum_{i=1}^n \log P(x_i \mid \theta) - \lambda \|\theta\|^2 \right]$$

翻译成人话：

| 项 | 在干吗 |
|---|---|
| $\sum \log P(x_i \mid \theta)$ | 拟合数据（MLE 也干这个） |
| $-\lambda \|\theta\|^2$ | 惩罚参数太大（L2 正则化） |

**MAP with 高斯先验 = MLE + L2 正则化。**

> L2 正则化（权重衰减）不是工程上的 trick。它是"参数应该服从以 0 为中心的高斯分布"这个信念的数学表达。

### 拉普拉斯先验 → L1 正则化

假设先验是拉普拉斯分布：$P(\theta) \propto \exp(-\lambda |\theta|)$

→ $\log P(\theta) = -\lambda |\theta|$ → MAP = MLE + L1 正则化（稀疏）

### 用温度测量的例子直观感受区别

温度传感器测了 2 次：15.0, 16.0。噪声 σ=1。先验：θ ~ N(25, 1)。

| 方法 | 答案 | 怎么来的 |
|---|---|---|
| MLE | 15.5 | 只看数据：两次测量均值 |
| MAP | ≈ 21.0 | 数据说是 15.5，先验说是 25，MAP 在中间折中 |
| 先验极强（σ₀→0） | ≈ 25 | 先验压倒数据，接近不看数据 |
| 先验极弱（σ₀→∞） | ≈ 15.5 | 先验没有约束力，退化为 MLE |

MAP 不会因为两次测量异常就被彻底带偏——先验在兜底。

## MSE / MAE 与 MLE / MAP 的完整关系图

把所有对应关系放在两张表里：

**损失函数 ← 似然（噪声假设下的 MLE）**

| 损失函数 | 统计来源 | 分布假设 | 场景 |
|---|---|---|---|
| MSE | MLE | 高斯噪声 | 回归默认 |
| MAE | MLE | 拉普拉斯噪声 | 回归（抗异常值） |
| BCE | MLE | 伯努利 | 二分类 |
| 交叉熵 | MLE | 类别分布 | 多分类 |

**正则化 ← 先验（参数假设下的 MAP）**

| 正则化 | 统计来源 | 参数先验 | 效果 |
|---|---|---|---|
| L2 | MAP | 高斯分布（参数集中在 0 附近） | 权重整体缩小 |
| L1 | MAP | 拉普拉斯分布（参数偏好为 0） | 权重精确归零（稀疏） |

可以自由组合——**先验和似然是关于两个不同东西的假设，互不冲突**：

| 组合 | 含义 | 场景 |
|---|---|---|
| MSE + L2 | 噪声高斯 + 参数该小 | 最常见：默认配置 |
| MAE + L1 | 噪声拉普拉斯 + 参数该稀疏 | 想抗异常值 + 想稀疏特征 |
| MAE + L2 | 噪声拉普拉斯 + 参数该小 | 抗异常值但不追求稀疏 |
| MSE + L1 | 噪声高斯 + 参数该稀疏 | 特征选择（LASSO） |

> **一句话**：MSE/MAE 回答"误差应该怎么算"（噪声假设 → 似然），L1/L2 正则回答"参数应该长什么样"（参数假设 → 先验）。MLE 只用前者，MAP 两者都用。

---

## 两种学派的世界观

| | MLE（频率学派） | MAP（贝叶斯学派） |
|---|---|---|
| 参数 θ 是什么 | 固定的未知常数 | 随机变量，有自己的分布 |
| 信息来源 | 只有数据 | 数据 + 先验信念 |
| 样本少时 | 容易过拟合 | 先验兜底，更稳 |
| 样本无限多时 | 趋近真实值 | 先验影响趋于零，趋近 MLE |
| DL 等价 | 无正则化的损失最小化 | 带 L1/L2 正则化的损失最小化 |

---

## 和深度学习的完整对应

```
MLE  → 最大化数据似然       → 最小化 MSE / BCE / 交叉熵
MAP  → MLE + 参数先验       → 最小化 MSE / BCE + λ‖W‖²（权重衰减）
贝叶斯推断 → 求完整后验分布  → VAE、贝叶斯神经网络
```

当你训练一个带 L2 正则化的分类网络时，你实际上在做的事是：

> "假设模型参数服从以 0 为中心的高斯分布（先验），找到能最好地解释训练数据（似然）的参数值（后验最大化）。"
