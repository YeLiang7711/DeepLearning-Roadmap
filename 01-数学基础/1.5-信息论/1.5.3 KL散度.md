# 1.5.3 KL 散度

> 属于：[[0-概述|信息论]] > 1.5.3
> 掌握程度：**会用** — VAE、蒸馏、正则化里到处都是它

---

## 定义：两个分布之间的"差距"

[[1.5.2 交叉熵|1.5.2]] 讲过：交叉熵 = 熵 + KL 散度。KL 散度就是**用 Q 编码 P 时多付出的信息量**：

$$D_{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)}$$

**它衡量的是：如果真实分布是 P，但你用 Q 来近似它，平均每件事多惊讶多少。**

---

## 三个关键性质

### 1. 永远 ≥ 0，等于 0 当且仅当 P = Q

这是 KL 散度最重要的性质（吉布斯不等式）：

$$D_{KL}(P \| Q) \geq 0, \quad D_{KL}(P \| Q) = 0 \iff P = Q$$

**直觉**：用错误的分布编码真实分布，永远不可能比用真实分布本身更高效。只有完全猜对时差距才为 0。

### 2. 不是对称的（和距离不同！）

$$D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$$

KL 散度不是距离（不满足对称性和三角不等式）。方向很重要：

- $D_{KL}(P \| Q)$：以 P 为基准（真实），看 Q 差多少 → "前向 KL"
- $D_{KL}(Q \| P)$：以 Q 为基准，看 P 差多少 → "反向 KL"

两者优化行为完全不同（这在 VAE 里很关键）：

| | 前向 KL $D_{KL}(P\|Q)$ | 反向 KL $D_{KL}(Q\|P)$ |
|---|---|---|
| 惩罚方式 | P 有概率但 Q 没有的地方 → 巨大惩罚 | Q 有概率但 P 没有的地方 → 巨大惩罚 |
| 效果 | Q 覆盖 P 的所有峰（平均化、over-spread） | Q 集中在 P 的一个峰（mode-seeking） |

### 3. 对数的基数无所谓（换底只是缩放）

log₂ 和 ln 只差一个常数倍，不影响优化方向。论文里常用 ln。

---

## 在深度学习中的三个经典用法

### 用法一：知识蒸馏

学生模型模仿教师模型的输出分布：

$$\mathcal{L} = D_{KL}(P_{\text{teacher}} \| P_{\text{student}})$$

学生学着把概率分布"对齐"到教师的输出——不只是学对错标签，还学教师的"软判断"（哪个类别和正确类别最接近）。

### 用法二：VAE 的损失项

VAE 的损失包含一个 KL 项，把编码器的输出分布拉向标准正态先验：

$$D_{KL}(\mathcal{N}(\mu, \sigma^2) \| \mathcal{N}(0, 1))$$

这项让潜变量空间保持"有结构"（接近标准正态），而不是随意散开。

### 用法三：正则化

某些训练方法用"模型输出分布与均匀分布"的 KL 散度做正则化，防止模型过自信。

---

## KL 和交叉熵的完整关系

$$H(P, Q) = H(P) + D_{KL}(P \| Q)$$

训练时最小化交叉熵 = 最小化 KL（因为 H(P) 是常数，不随模型变）——**这就是为什么"交叉熵损失"和"KL 散度损失"经常混用：训练目标完全等价。**

---

## 总结

| 概念 | 一句话 |
|---|---|
| KL 散度 | 用 Q 近似 P 时多付出的信息量 |
| 永远 ≥ 0 | 只有 P = Q 时等于 0 |
| 不对称 | $D_{KL}(P\|Q) \neq D_{KL}(Q\|P)$，方向和效果不同 |
| 蒸馏 | 学生对齐教师分布的 KL |
| VAE | 潜变量分布对齐标准正态的 KL |

> KL 散度 = 两个分布的信息量差距。它不是距离（不对称），但"越小越接近"的直觉成立——训练就是不断让模型的分布靠近目标分布。
