# 1.5.2 交叉熵

## 先看一个例子：天气预报员评分

假设你是天气预报评分员，评估两个预报员的水平。天气的真实分布（[[1.5.1 熵|1.5.1]] 的公平硬币比喻）：今天有雨的概率 P = 0.5。

**预报员 A**：总是报"各有 50%"。他每天报的分布 Q 和真实分布 P 完全一样。

**预报员 B**：最近很自信，报"90% 有雨，10% 无雨"——但他猜错了方向，实际上没雨。

**怎么给预报员打分？** 用"平均惊讶度"——每报一次，你的惊讶程度：

- A 的预报符合事实 → 惊讶度 = 真实分布的熵 H(P) = 1 比特
- B 的预报离谱 → 惊讶度 = **用 Q 的预测来算真实分布 P 的平均惊讶度**

这就是交叉熵：

$$H(P, Q) = -\sum_x P(x) \log Q(x)$$

**交叉熵 = 用"预测分布 Q"来编码"真实分布 P"时，平均每个事件需要的信息量。**

---

## 为什么分类损失用交叉熵

分类任务：真实标签是 one-hot（真实分布 P 只有一个位置是 1），模型输出预测分布 Q（Softmax 结果）。

$$H(P, Q) = -\sum_k P(k) \log Q(k) = -\log Q(\text{真实类别})$$

**交叉熵 = 模型给真实类别预测概率的负对数。**

- 模型给正确类别 0.9 的概率 → 损失 = -log 0.9 ≈ 0.11（小，好）
- 模型给正确类别 0.1 的概率 → 损失 = -log 0.1 ≈ 2.3（大，差）
- 模型给正确类别 0.0001 → 损失 = 9.2（灾难性的大）

这和 [[../1.3-概率统计/1.3.4 最大似然估计与最大后验估计|1.3.4]] 连上了：**交叉熵 = 类别分布假设下的最大似然估计**（最大化正确类别的 log 概率 = 最小化交叉熵）。

```python
# PyTorch：交叉熵损失 = 分类默认损失
loss = torch.nn.CrossEntropyLoss()   # 内部自带 Softmax
```

## 交叉熵 vs 熵：多出来的"惊讶"是什么

熵 H(P) = 用真实分布 P 编码自己的平均信息量（最小可能）。
交叉熵 H(P, Q) = 用错误分布 Q 编码真实分布 P 的信息量。

**交叉熵永远 ≥ 熵**（预测分布不可能比真实分布更"高效"）。多出来的部分就是 [[1.5.3 KL散度|1.5.3]] 的 KL 散度：

$$H(P, Q) = H(P) + D_{KL}(P \| Q)$$

```
真实分布的熵（最小惊讶度）
    +
预测带来的额外惊讶度（KL 散度）
    =
交叉熵（实际惊讶度）
```

> **理解顺序**：熵是"猜对的最佳成绩"，交叉熵是"实际成绩"，KL 散度是"差距"。分类训练就是不断减小这个差距（KL 散度），直到预测分布接近真实分布。

---

## 总结

| 概念 | 一句话 |
|---|---|
| 交叉熵 H(P,Q) | 用 Q 编码 P 的平均信息量（实际惊讶度） |
| 分类损失 | 交叉熵 = -log(正确类别的预测概率) |
| 和熵的关系 | H(P,Q) = H(P) + KL(P‖Q) |
| 和 MLE 的关系 | 交叉熵 = 类别分布假设下的负对数似然 |

> 交叉熵 = 用错误分布做预测时的平均惊讶度。训练分类模型就是不断减少这种惊讶，直到模型分布接近真实分布。
